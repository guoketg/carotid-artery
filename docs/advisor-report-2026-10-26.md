## 0. 60 秒版本

我们用 TransUNet（R50+ViT-B_16）做 B 型超声颈动脉斑块分割，单通道原图基线的 Dice 是 **90.92%**。在此基础上试了三条改进路线：小波域三通道早融合、小波引导的注意力侧支、以及双骨干多级融合。**到现在为止，没有任何一种配置在 Dice、ASSD、HD95、面积偏差这四项上取得相对基线的显著增益。**

目前唯一一个"融合分支真正参与训练"的配置是双骨干窗内融合：Dice 90.51%，相对基线 −0.41 个点，四项指标全部变差。不过还不能对这个负结果下统计结论：基线用的是 batch 8 一步，双骨干用的是 batch 4 + 梯度累积 2，两者梯度路径不同；而且只有单个随机种子。下一步先把这两个混杂消掉，再决定这条线是否继续。

需要说明一点：之前三个双骨干配置（90.79%~91.17%）其实都没跑对——融合模块的输出投影和残差门控同时零初始化，梯度互相锁死，融合分支全程没参与训练，那些数字只是噪声。这个实现 bug 已经修了（记录见 §3），修完才拿到上面那个第一个有效结果。

## 2. 已完成的三条路线与结论

### 2.1 小波三通道早融合

把三张图拼成三通道直接送入同一个编码器，不加任何融合模块：

- **原图通道**：原图本身；
- **去噪重建通道**：对数域一级 Haar 小波分解 → VisuShrink 软阈值去掉斑点噪声 → 逆变换，再拉回原图量级；
- **高频能量通道**：三个方向子带的平方和的平方根，反映边界/纹理强度。

设计意图是让网络直接"看到"去噪后的结构和边界能量。结论：**没有增益**。

### 2.2 小波引导的注意力侧支（旧轻量路线）

在 ViT 输出瓶颈（14×14，196 个 token）处，用一路 4 层卷积的小侧支（约 0.9M 参数）从高频能量通道生成 K/V，主分支作 Q，做一次 4 头跨注意力后残差加回。

结论：**没有增益，该路线已否定**。而且结构上本就不该有增益——侧支输入是原图通道的确定性函数，没有引入新信息；融合只做一次，且切在分辨率最低的 14×14 层，而增益本应体现在边界指标（HD95）上。

### 2.3 双骨干交错四级融合

改为主路只吃原图通道（复制为 3 通道），侧路吃小波分解的水平/垂直/对角三个方向子带（LH/HL/HH，即去掉低频后的方向细节）。两路骨干按 stage 交错执行，在 112×112、56×56、28×28、14×14 四个接点上做双向跨支融合。总参数 121.66M（主路 105.28M + 侧路 12.68M + 融合 3.70M）。

设计依据来自文献：MSFA-Net 的消融显示"把第二路加回来"值 +8.56 Dice，而"加/换融合模块"只值 +0.45~2.18，所以第二路的信息源比融合算子更关键。

## 3. 实现缺陷记录：融合分支零初始化死锁（已修复）

> 这一节只是把一个自己写错的地方和修复过程记下来，不构成方法上的贡献。

### 3.1 现象

2026-10-25 逐个检查融合层的门控系数（γ）时发现：多个双骨干配置的 γ **从第 1 个 epoch 到第 120 个 epoch 一直是精确的 0.0**，不是"很小"，是恒等于零。

### 3.2 机理

融合写成残差形式 `A' = A + γ · GN(Proj(Attn(...)))`，而实现里 `Proj`（输出投影）和 `γ` **同时**零初始化。于是：

- `Proj` 权重全零 → `Proj(·) ≡ 0` → GroupNorm 对全零输入输出恰为 0 → 残差项恒为 0；
- 于是 `∂L/∂γ = ⟨∂L/∂A', 0⟩ = 0`，γ 永远停在 0；
- 而 `γ = 0` 又使 `∂L/∂Proj = γ · (...) = 0`，投影也永远停在 0。

**两个零互为前提，谁都无法先离开零。** 整个融合块退化为恒等映射，`qkv`、`norm` 也因上游恒零而拿不到梯度。这不是"学得慢"，是永远不会学。

判据可以总结成一句：**一条乘法链上只能有一个零，并且这个零的梯度不能依赖它自己。** ReZero 之所以成立，是因为只保留 γ=0、投影正常初始化，`h(x) ≠ 0`，γ 一步就能离开 0。而 `Proj` 零初始化本身没有换来任何东西——恒等起点由 γ 就提供了，它只是多加了一道梯度闸门。

### 3.3 影响

修复前的三个双骨干配置跑的都是冻结版代码，它们等价于"基线 + 一批不参与计算、也不更新的参数"。所以：

| 配置 | Dice | 融合分支状态 |
|---|---|---|
| 单通道原图基线 | **90.92%** | — |
| 三通道早融合 | 90.79% | 无该模块 |
| 三通道＋小波引导注意力 | 90.87% | 无该模块 |
| 双骨干·窗内/全局自适应融合 | 91.17% | **冻结** |
| 双骨干·可变形大核 | 90.88% | **冻结** |
| 双骨干·自适应＋跨尺度回流 | 90.93% | 跨尺度部分在学，四级融合冻结 |

全部落在 90.79%~91.17%、极差 0.38% 的噪声带内，**不能作为融合有无增益的证据**。特别地，91.17% 这个"看起来最好"的数字是冻结模型的噪声，不能当成结果展示。

### 3.4 同一处还有一个结构上的问题：最深接点是死支路（已修复）

最深接点（14×14）做完融合后，侧路输出 `b` 再没有被任何算子引用，解码器只拿主路特征。后果是这一层的侧路方向根本不存在梯度路径，`gamma_b` 从第 0 步起就是精确 0，连带 `qkv_b`、`proj_b`、`norm_b` 悬空，合计约 118 万参数零梯度。这是计算图上少了一条边，与上面的数值死锁是两回事。

改法是把该接点从并行双向改成串联双向：先更新侧路得到 `B2`，主路再用 `qkv_b(B2)` 重新取 K/V 去更新自己，这样侧路的残差项就进了主路的计算图。因为 `gamma_b` 初始为 0，第 0 步 `B2 == B`，前向结果与原并行实现逐元素相同（`max|Δ| = 0`）；从第 1 步起侧路方向已有非零梯度。只有最深层开这个模式，前三层仍是并行双向。

### 3.5 已加的观测手段

训练循环每个 epoch 结束后，把所有名字含 `gamma` 的参数取绝对值最大值写入日志。这样第 1 个 epoch（约 30 秒）就能判断门控是否在被训练，不必等 epoch 99 第一次存权重。判读规则：从 1e-4~1e-2 起步且逐 epoch 增大 = 正常；恒为精确 0 = 断路或死锁。

## 4. 修复后的第一个有效结果

修复死锁后（保留 γ 零初始化，去掉输出投影的零初始化，已验证第 0 步与基线逐元素 `max|Δ| = 0`、第 0 步 γ 即有非零梯度），跑了窗内融合配置：

- 112×112 用 8×8 窗内注意力，56×56 与 28×28 用 7×7 窗内注意力，14×14 接点用全局注意力；
- 前三个接点并行双向，最深接点当时仅主路→侧路单向（3.4 的死支路是这次跑完之后才修的，所以这组 90.51% 里最深层的侧路方向仍未参与）；
- batch 4 + 梯度累积 2（等效 batch 8），seed 1234，未开跨尺度回流。

| 配置 | Dice | ASSD (mm) | HD95 (mm) | \|ΔArea\| (mm²) | 融合分支 |
|---|---|---|---|---|---|
| 单通道原图基线 | **90.92%** | **3.809** | **10.022** | **945.1** | — |
| 三通道早融合 | 90.79% | 3.818 | 9.997 | 1017.9 | — |
| 三通道＋小波引导注意力 | 90.87% | 3.892 | 10.041 | 1065.0 | — |
| **双骨干·窗内融合（融合真实在学）** | **90.51%** | 3.940 | 10.127 | 1024.8 | **正常更新** |

相对基线：Dice **−0.41%**、ASSD +0.131、HD95 +0.105、面积偏差 +79.7，**四项全部变差**。

逐 epoch 看（12 个评估点，同一 epoch 上配对）：

- **10 个点低于基线**，2 个点略高（ep20 +0.20 个点、ep110 +0.04 个点）；
- 最大差距在 ep50（−1.34 个点），ep70 之后差距基本收窄到 0.25 个点以内，ep120 为 −0.41；
- 这些 epoch 之间强相关，不能当作 12 个独立样本做符号检验，只作方向性参考。

γ 实测（ep1–ep30）：前三个接点的两个方向都在学（0.01~0.10 量级），最深接点 `gamma_b` 30 个 epoch 一次没离开 0，与 3.4 的判断一致。3.4 已经改好，下一轮重跑时这一项应该能看到非零值（但它的梯度是两层 γ 相乘的二阶小量，会明显比前三层慢）。

### 结论口径

严格表述是：**没有观察到增益，方向上偏向变差**。不能说"显著变差"——单 seed 无法估计方差，0.0041 又落在前面测得的配置间噪声带（0.0038 极差）量级内。

## 5. 当前结论的边界：两个必须先消掉的混杂

1. **batch 口径不一致**。基线、三通道早融合、小波引导注意力这三组是 batch 8 直接一步；双骨干全部是 batch 4 + 梯度累积 2。等效 batch 相同，但梯度路径不同（BN 统计、优化器步频都不一样）。这 0.3~0.4 个点的差异里有多少来自这里，目前**未知**。需要补一个 batch 4 + 梯度累积 2 的单通道基线。
2. **单 seed**（1234）。要对"变差"下统计结论，至少需要 3 个种子（1234 / 2024 / 3407）。

另外还有一条与结论直接相关的观测：**为什么融合真正学起来反而更差**，目前只有假设、没有证据。可能的原因是侧路吃的是去掉低频的方向子带，语义弱，注入的 K/V 更接近噪声；前两级融合的 γ 稳定在 0.02~0.09，相当于每层叠加 2%~9% 的扰动，而超声斑块边界本身模糊、容错低。这需要在修完最深接点之后才能判断。

| 5 | 视结果决定是否补跑跨子集（Zhongnan）复现 | 只在 SPARC 成立则结论限定单中心 |

判定阈值**跑之前写死**，避免事后解释：主指标 HD95 / ASSD，要求 **HD95 下降 ≥ 0.5 mm 且病例级 Wilcoxon p < 0.05**；Dice 只作参考门槛。不达标即判为无增益，转负面结果，融合线停止投入。

资源约束也需要说明：全量 SPARC 单个 120-epoch 任务实测约 2.2–2.5 小时，期间 GPU 利用率只有 63%，瓶颈是数据加载（`num_workers=1`，受本机内存限制，不能调大）。要跑 3 个种子 × 多配置 × 两个子集，这个吞吐是不够的。

## 7. 需要老师决定的问题

1. **这个方向是否接受"负面结果 + 机理解释"作为阶段性产出？** 目前的证据链是完整的（结构分析 → 实现缺陷 → 修复后重测 → 仍无增益），但确实没有涨点。如果必须要有正向结果，需要讨论换路线。
2. **主指标定 HD95/ASSD 还是 Dice？** 现在两套口径并存，会直接影响后面所有结论的措辞和判定阈值。
3. **是否需要投入资源解决数据加载瓶颈？**（换机器、放宽内存约束、或改成预处理缓存成 npy）这决定了能不能在合理时间内完成多种子、多子集的验证。
4. **如果融合线停止，优先转哪个方向？** 文献里在本任务上真正有增益证据的是**显式边界监督**（MBFF-Net 的 BPS，单项 +0.044 Dice，是全表最大单跳），另一条是跨中心泛化。这两条的成本和风险差别很大。

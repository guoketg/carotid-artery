# 一、先回答核心问题：为什么要把小波变换特征引入医学图像分割？
医学图像（超声、电镜EM、病理切片）天生有几个空域卷积很难搞定的痛点，小波刚好对应解决这些痛点：
1. **CNN下采样会丢失高频边缘细节**
普通U-Net靠池化/跨步卷积做下采样，本质是做低通滤波，会直接抹掉边缘、微小纹理、粘连边界这些高频信息；而**小波变换可以显式分离低频轮廓 + 高频细节**，低频抓病灶整体形状，高频保留边界、细微纹理，不会在编码阶段直接丢失。
2. **医学图像灰度分布混杂、对比度低、噪声强**
比如超声散斑噪声、电镜图明暗不均、病理细胞核粘连。空域里病灶和背景灰度很接近，卷积很难区分；但在小波频域上，**噪声、边缘、病灶轮廓处在不同子带**，可以单独对高频子带做增强或者降噪，不用连带破坏低频的语义轮廓。
3. **多分辨率天然匹配医学病灶尺度多变的特性**
小波是多尺度分解，一次变换直接得到不同分辨率的频带子带，天然契合医学病灶大小差异巨大的特点（很小的微病灶、大肿块共存），不需要额外堆叠大量空洞卷积、多尺度分支，设计更简洁。
4. **和FcaNet/DCT路线形成互补**
DCT（Syn-Net、FcaNet）是**全局块频域变换**，擅长全局频率统计、通道层面的频率注意力；小波是**局部多分辨率频域分解**，更适合逐层拆分轮廓和边缘，适合做双流融合。

> 一句话总结小波引入动机：**显式解耦轮廓语义（低频）与边缘纹理（高频），弥补卷积下采样不可逆的高频信息损失，在低对比度、噪声强的医学图像里更好保留边界。**

# 二、全部7篇频域论文分组 + 横向区别讲解
先分组，分成两大路线：**小波Wavelet路线**、**DCT/谱频域路线**
## 组A：小波路线（XNet → GobletNet → WMREN）
都是用小波分解，但是对低频、高频的使用策略完全不一样
1. **XNet（ICCV2023，同团队开山）**
    做法：小波把原图拆成**低频子带LL + 三个高频子带(LH/HL/HV)**；构造双流：低频分支、高频分支，两个分支独立编码，最后融合；支持全监督+半监督。
    特点：**低频、高频同等重视，双流并行**。低频管整体病灶区域，高频管边缘；目标是通用生物医学图像，结构简单。
    局限：高频和低频只是简单双流，没有侧重挖掘高频的判别信息，高频分支容易被噪声干扰。

2. **GobletNet（TMI2025，XNet续作，你缺的这一篇）**
    做法：小波只提取**高频子带单独作为一条增强分支**，主分支还是原始图像空域卷积分支；把高频分支提取的边缘纹理，用FAM注意力模块融合进主分支。低频直接交给主卷积分支自己学习，不再单独开低频编码器。
    特点：**放弃独立低频分支，重点强化高频边缘**。任务是电镜EM图像分割，EM图像最核心难点就是膜边界微弱、细结构容易糊掉，作者认为低频轮廓靠普通卷积足够学好，额外小波只用来补边缘纹理。
    和XNet对比：XNet是「低频+高频双编码」；GobletNet是「原图主分支 + 小波高频辅助分支」，结构更轻量化，专门聚焦精细边缘。

3. **WMREN（IJCAI2025）**
    做法：Haar小波嵌入U-Net编码器每一层，每一层都做多尺度小波区域增强；不光提取高频，额外设计对比度增强模块，对小波子带做区域加权。
    特点：**小波不是单独一个外部分支，而是嵌入U-Net每一层，逐层做频域增强**。XNet/GobletNet都是输入层做一次小波分解；WMREN是编码每一层都做小波多尺度精炼，对抗深层特征退化。

## 组B：DCT/频域滤波路线（FcaNet、Multi-Scale Frequency Domain Filter、Syn-Net）
不用小波，用离散余弦变换DCT或者频域滤波，思路和小波路线完全不同
1. **FcaNet（ICCV2021，频域注意力源头）**
    做法：理论证明GAP全局平均池化是DCT的低频分量；直接在通道注意力里面，用多个DCT频率分量替换GAP，拿到更丰富的频率通道描述。
    特点：**不是拆分高低频图像，是在通道注意力层面做频域采样**。最初是分类任务，不做图像分解，没有双流，是轻量即插即用注意力。
    局限：只建模通道频率统计，没有显式提取边缘细节，很少单独用来抓边界。

2. **Medical Image Segmentation Network Based on Multi-Scale Frequency Domain Filter（Neural Networks 2024）**
    做法：设计可学习的多尺度频域滤波模块MFDF，在频域对特征图做可学习滤波，抑制噪声频率、增强目标对应的频率分量，搭配空洞残差卷积。
    特点：**可学习频域滤波器**，不是固定DCT/小波基；滤波器参数跟着网络一起训练，让网络自己学哪些频率需要保留。偏向空域-频域混合滤波降噪。

3. **Syn-Net（JBHI2025，你的主线核心）**
    做法：同步CNN（局部）+ Transformer（全局）双编码器，**在特征层面做DCT频域交叉融合FrCFusion**；不是输入图像做频域分解，是两个分支的特征图送入DCT频域交互。
    特点：同步并行双流，融合发生在特征层级的频域空间，而不是输入图像；核心解决超声灰度混叠，靠频域交互放大肿瘤和背景频率分布差异。
    和小波路线最大区别：小波是**输入图像分解成低频/高频子图再送入网络**；Syn-Net是**空域先提取特征，再把特征变换到DCT频域做跨分支信息交换**。

## 组C：谱精炼路线 WeaveSeg（ICCV2025 Highlight）
4. **WeaveSeg（ICCV2025，细胞核实例分割）**
    做法：自适应谱特征精炼ASR + 迭代对比编织ICW。这里Spectral（谱）不是小波，是对特征做频域筛选、抑制冗余频率分量，配合迭代反馈机制，专门解决细胞核粘连、实例边界模糊。
    特点：任务是**实例分割（区分一个个细胞核）**，前面所有都是语义分割；频域用来提升实例之间的特征可分性，搭配迭代反馈优化，不是简单双流融合。

# 四、最关键的一条分界线（写论文非常好用）
- **小波系列（XNet/GobletNet/WMREN）：图像前置分解路线**：原图先拆低频高频子带，再送入网络学习；优点是物理意义直观，边缘信息可控；缺点是分解在输入阶段，高频分支容易引入噪声。
- **DCT/Syn-Net路线：特征后融合路线**：网络先在空域学习局部/全局特征，再把特征映射到频域交互；优点是特征已经经过初步筛选，频域交互更聚焦判别信息；缺点是计算量更大，频域可解释性弱于小波。

## 5.1 上文三处需要校正

| 上文表述 | 实际情况 |
|---|---|
| XNet 高频子带写作「LH/HL/**HV**」 | 是 `LH`（水平细节）、`HL`（垂直细节）、`HH`（对角细节），没有 HV |
| GobletNet「小波只提取高频子带单独作为一条增强分支」 | 不完整。GobletNet 的高频图是 `H = H_L(I) + L_H(I) + H_H(I) + λ·L_L(I)`，**λ 混入了一小部分低频**用于抑制噪声，不是纯高频 |
| 「WMREN 每一层都做小波多尺度区域增强」 | 更准确：小波主要用在编码器的 **WRDM 里替代/并联下采样**（`[X_L, X_HL, X_LH, X_HH] = DWT(X)` → 1×1 融合），解码器侧是 SAFM 空间自适应融合 + CREM 对比精炼，**不是每一层都做小波** |

## 5.2 逐篇关键数字

### XNet（ICCV 2023）

- 消融（Table 7，JI 指标）：

| 配置 | JI | 半监督 JI |
|---|---|---|
| Raw only | 82.03 | 78.52 |
| LF only | 80.77 | 76.30 |
| **HF only** | **54.50** | 52.56 |
| LF+HF 无融合 | 75.82 | 66.78 |
| LF+HF+融合 | **84.77** | 80.89 |

- 模型量：XNet 326M / 83G MACs；XNet− 82M / 21G；XNet−− 20M / 5G。
- **关键**：raw-only 基线是**单编码器**，而 XNet 是双编码器。+2.74 的增益里混着「多了一个编码器」的容量红利，不能全部归因于频域融合。

### GobletNet（TMI 2025，XNet 同团队）

- 结论顺序（正文消融）：① HF 图作为**额外输入通道**即有提升；② 再加**独立 HF 编码分支**再提升；③ **引入 LF 分量反而变差**；④ **二级小波无显著提升**；⑤ 小波基在多数数据集不敏感（UroCell 例外，最好/最差 Jaccard 差 8.89%）；⑥ FAM 加在**所有编码层**最好。
- 融合模块 FAM：`concat → 1×1 → fusion_feat → 1×1 → 两张 attention map`，分别乘回两路。
- 训练：4×RTX3090，SGD 0.9，batch 16，200 epoch。
- **关键**：这是**参数量对齐**后的实验，结论比 XNet 严格——只有高频有用，低频是冗余。

### BDFR-Net（待提交，胎儿超声 IUGC 2024）

- 单骨干 PVT-B2，**在特征级**做双域解耦 DDBE：
  - ECA 先抑制散斑；
  - 高频支：`F_ECA` 做 2D-DWT → 取 `LH/HL/HH` → concat → 1×1 降回 C → 3×3 → BN → 转置卷积上采样 → 通道注意力；
  - 低频支：取 `LL` → 5×5 卷积 → BN → 上采样 → 通道注意力；
  - 另有空间上下文分支 CTX。
- skip 上用 ACAM（空间-通道双注意力）做跨层对齐。
- 消融（mean Dice / ASD / HD）：baseline 84.74 / 1.17 / 14.55 → +HF **85.53** → +HF+LF 85.95 → +HF+LF+CTX 86.37；仅 ACAM 85.21；完整 **86.83**。
- 训练：256×256，AdamW 1e-4，batch 16，3 次独立运行。
- **关键**：没有第二编码器，全部增益来自**特征级解耦 + skip 对齐**。

### WMREN（IJCAI 2025）

- Table 4（Synapse）：H-Net（纯小波下采样）81.29 / R-Net（纯卷积）82.59 / **WMREN 84.40**（HD95 15.65）。
- Table 5：baseline 82.72 → +SAFM 83.52（**HD95 反而 21.86**）→ +SAFM+CREM **84.40**。
- **关键**：小波单独**不如**纯卷积，只有「小波 + 卷积并行 + 融合」才有效。

### Syn-Net（JBHI 2025，乳腺超声）

- 同步双支：ResNet34（局部）+ Swin（全局），**三层**。
- FrCFusion：通道分 n 组 → 每组一组 2D-DCT 基做频率感知（FcaNet 式）→ concat → FC + sigmoid → 通道重加权；另一路空间注意力；输出 `residual(cat[Fre_S, Fre_R, A])`。
- 另外有全尺度深监督，损失 `mean(BCE + weighted IoU)`。
- **关键**：融合的是**局部 vs 全局两骨干**，不是 raw vs HF；DCT 用在**通道注意力**上，不是图像分解。

### MFDF / FDFUNet（Neural Networks 2024）

- `Y = IFFT(W ⊙ FFT(X))`，`W` 为全局可学习谱权重矩阵，与深度空洞可分离卷积、ASCA 通道注意力组合。
- **关键**：`W` 全图共享，**空间不敏感**——对「同一张图不同区域需要不同频带」的情形表达能力有限。

### WeaveSeg（ICCV 2025，细胞核实例分割）

- ASR：在学习型低通 `W_LP ∈ R^{K²×2H×2W}`（受 Hamming 窗隐式调制）上做 `F_LP = PixelShuffle(W_LP ⊛ F_high)`；高频侧用局部相似性引导重采样恢复细节；与迭代对比编织 ICW 形成闭环。
- **关键**：频域处理放在**解码器上采样路径**，且用于**拉开实例间距**，不是语义分割的边界增强。

## 5.3 三篇结论为什么不一致

差异来自四个维度，不是谁对谁错：

| 维度 | XNet | GobletNet | BDFR-Net |
|---|---|---|---|
| 基线容量 | 单编码器 82.03，模型 326M | **参数量对齐** | 单骨干，无第二路 |
| 「低频」是什么 | `LL` 近似图，约等于模糊版原图 | 主分支已是原图，再灌 `λ·LL` = 冗余 + 噪声 | 特征级 `LL` 支，与 HF 支并列 |
| 融合位置 | 图像级（双编码器） | 图像级（额外通道/额外编码器） | **特征级**（单骨干中间层） |
| 任务/数据 | EM / 病理，边界锐利 | EM 图像 7 数据集 | 胎儿超声（与我们同域） |

**结论**：XNet 的 +2.74 含容量红利；GobletNet 把容量对齐后发现「只有高频有用、低频有害」；BDFR-Net 说明「在特征上解耦比在输入端再开一个骨干更划算」。三者共同指向：**别在输入端复制骨干，要去特征级做。**

## 5.4 融合模块六档（按可训练性排序）

| 档 | 做法 | 代表 | 额外参数 | 风险 |
|---|---|---|---|---|
| 1 | `concat` + 1×1 降维 | XNet | 极小 | 两路强度不匹配时会被一路吞掉 |
| 2 | 门控加权（两张 attention map 乘回两路） | GobletNet FAM | 小 | 基本稳定 |
| 3 | 频域通道注意力（分组 2D-DCT 基 + FC + sigmoid） | FcaNet / Syn-Net FrCFusion | 中 | 需选频带分组数 |
| 4 | 可学习谱滤波 `IFFT(W ⊙ FFT(X))` | MFDF | 中 | 空间不敏感 |
| 5 | 空间自适应 / 可变形大核 / 学习型低通 | WMREN SAFM / WeaveSeg ASR | 大 | 小数据易过拟合 |
| 6 | 跨支交叉注意力（双向 Q/K/V 互换） | 本项目 `BidirCrossAttention` | 最大（最深受 2.37M） | γ 与 `W_o` 同时零初始化会永久冻结 |

**本项目现状在第 6 档**，而文献里跑出稳定增益的是第 1–3 档。4 个接点共 3.70M 融合参数 + 120 epoch + 单 seed，融合分支很可能还没学到东西就训练结束了。

## 5.5 频率注入位置四选一

| 位置 | 做法 | 证据 | 代价 | 代表 |
|---|---|---|---|---|
| 输入级 | 多一张 HF 图当通道 | 强 | 最低（+1 通道） | GobletNet |
| **特征级** | 中间特征做 DWT 解耦 | 强 | 中 | BDFR-Net（+2.09） |
| skip 级 | 跳连上做空间-通道对齐 | 中 | 中（+0.3~0.5M） | BDFR-Net ACAM（+0.47） |
| 损失级 | LF/HF 双视图一致性正则 | 中 | 高（2 次前向） | XNet 半监督 |

## 5.6 「不局限于两种变换」的变换工具箱

按**它提供什么**分类，而不按名字：

| 变换 | 提供什么 | 代价 | 适合位置 |
|---|---|---|---|
| Haar / Db2 小波 | 局部多分辨率 + 方向性细节 | 极低，可逆 | 输入级、特征级 |
| DCT 分块 | 全局频谱基，通道注意力友好 | 低 | 通道注意力（Syn-Net 式） |
| FFT + 可学习掩码 | 全局谱滤波，任意频带 | 中 | 特征级（MFDF 式） |
| 可学习低通/高通（深度卷积 + Hamming） | 数据驱动频带，免选基 | 中 | 解码器上采样路径（WeaveSeg 式） |
| Gabor / 可变形卷积 | 方向 + 尺度选择性 | 高 | 小数据不建议 |
| 二阶统计（协方差 / 格拉姆） | 纹理风格 | 中 | 增益不稳，不建议起步 |

**判断**：变换种类不是主要矛盾。GobletNet 实测小波基差异多数 <1%、二级小波无收益；WMREN 直接表明小波单独（81.29）不如纯卷积（82.59）。「多试几种变换」如果发生在错误的注入位置上，不会改变结论。真正值得换的一处：做通道注意力式频率重加权时，**DCT 比小波自然**（Syn-Net 在超声乳腺上验证过）。

## 5.7 对本项目「双骨干四级融合无增益」的诊断（按可能性排序）

1. **融合可能根本没在学**：`γ` 零初始化是好事，但若 `W_o` 也接近零 + 120 epoch，`γ` 可能一直停在 1e-3 量级。低成本判定：打印 checkpoint 里 4 个接点的 `|γ_A| / |γ_B|`。
2. **HF 图构造方式不对**：现状是三个半分辨率子带 `concat` 后双线性上采样到 224²，会产生 2×2 块状伪影且三通道高度冗余。XNet / GobletNet 都是 **IDWT 重建一张全分辨率 HF 图（`LL` 置零）**。
3. **口径不一致**：baseline 用 `bs8`、融合系列用 `bs4 + grad_accum 2`，等效 batch 相同但 BN 统计与优化步频不同。
4. **统计功效不足**：+0.5 Dice、SD≈2 → 约需 128 对病例才有 80% 把握；单 seed + 现有测试集测不出 0.3 的差。
5. **天花板效应**：Dice 90.9%、HD95≈10，残差集中在边界几个像素；融合模块改善的是全局语义一致性，这里缺的是边界锐度。
6. **颈动脉回声特性**：斑块边界常是「低回声斑块 vs 高回声外膜」的**低频对比**，真正难点是钙化后方声影导致的信号缺失——这是「信息不存在」，任何频域增强都补不回来。

## 5.8 推进顺序

| 步骤 | 内容 | GPU 代价 |
|---|---|---|
| Step 0 | 打印 4 个接点 `|γ|`；HF 图改为 IDWT 重建（`LL` 置零） | 0 |
| Step 1 | baseline 用 `bs4 + grad_accum 2` 重跑，seed 1234 / 2024 / 3407 | 3 job |
| Step 2 | 最小验证：stem 输入 3 → 4 通道（原图 3 + IDWT 重建 HF 图 1），新增 27 个参数 | 1 job |
| Step 3 | 若 Step 2 有效：回单骨干，3–4 级特征做 DWT 解耦（高频支 1×1→3×3→上采样→通道注意力；低频支 5×5→上采样），skip 加轻量空间-通道对齐，融合用**第 2 档门控** | 1–2 job |
| Step 4 | 可选：LF/HF 双视图一致性正则或半监督 | — |

**不做的事**：在没解掉 Step 1 之前，不再新增任何融合算子（第 4–6 档）；不再追加第 5–6 种小波基做对比。

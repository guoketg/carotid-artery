## D1 预处理：Haar DWT（1 级）✅

- 不用 FFT 直接当输入通道：全局频谱无空间定位、相位不对齐，回答不了「边界在哪」。
- Haar 1~2 级足够，3 级以上在超声里基本是斑点；当前实现只有 1 级，2 级仅为 P2 实验预留。
- 手写固定 2×2 卷积核做 DWT/IDWT：无参数、可 GPU、可逆，不引第三方依赖。
- 边界用对称延拓，避免振铃。

## D2 三通道构造 ✅（C2 已降级，不再进主路径）

在**对数域**分解：`log1p(x)` → Haar DWT → 软阈值 → IDWT。

| 通道 | 实际运算（以 `networks/wavelet.py` 为准） | 定位 |
|---|---|---|
| **C1** | 归一化后的原图 | 主路径，必需 |
| C2 | `expm1(IDWT(LL, softT(LH/HL/HH)))`，再对齐到 C1 的 mean/std | **只做消融**，不进主路径 |
| **C3** | `sqrt(LH²+HL²+HH²)` → 逐样本 z-score → 双线性上采样回 224 | 主路径，第二路输入 |

- 旧文档写「C3 → 高斯平滑」与实现不符，**以本表为准：没有高斯平滑，只有双线性上采样**。
- 软阈值：`T = σ·sqrt(2·logN)`，`σ = median(|detail|)/0.6745`。
- C1 先按 1%–99% 分位截断再拉伸，抑制设备增益差异；C2 复用 C1 的 mean/std。
- **C2 为什么降级**：输入级去噪替换原图，收益不稳定且常为负（denoising benchmark Table V/VI：同域 22 好 / 87 平 / 24 差，跨域 114/252 变差，Friedman 无方法优于原图）；把去噪特征塞进分割网络会掉点（同文 Table A14）。
- **禁止 `C3 × λ`**：C3 被逐样本标准化，乘常数会被抵消；要改变高频贡献只能换尺度（P2）或换通道构成。

## D3 编码：F1 共享权重双输入（主方法）⏳

| 编号 | 形式 | 参数 | 状态 | 说明 |
|---|---|---|---|---|
| **F1** | 同一套 R50+ViT 分别吃 C1 与 C3 | 105.28M（**不增**） | ⏳ 主方法 | 两路差异全部来自输入差异，增益归因干净 |
| F2 | 两套独立 R50+ViT，均 ImageNet21k 初始化 | 210M | ⏳ 2026-10-24 升级为 D11 的方案 B | 原定「最后做、只量化容量」，现因「第二路信息」论证改为候选主线；需 batch 4 + 梯度累积，且侧路 BN 要换 GN |
| F3 | 轻量 CNN 辅支（0.1M） | 105.1M | ❌ 不作主方法 | 仅 sanity check，文献里这类轻支已证明增益 ≤0.7 Dice |

**F1 的实现方式（关键，决定显存）**：不写两条支路，而是把 `[C1×3; C3×3]` 沿 **batch 维**拼成 2B 做一次前向，前向后 split。共享权重下这与「两次前向」数学等价，BN 统计更稳；显存/耗时与现在 batch 8 单输入持平（baseline 实测峰值 3.3GB），**不翻倍**。

**通道契约**（ViT patch embedding 固定 3 通道）：

- 单通道视图 → `repeat(1,3,1,1)`；
- 两通道视图 → `[C1, C3, 0]`，第三通道置零（不提供信息，也不破坏预训练权重）；
- 任何改动通道布局的地方必须显式写出顺序，**禁止 `x[:, 2:3]` 这种隐式索引取 C3**。

**为什么 F2 降级**：已读到的双编码器**全部是异构互补**（PVTv2+CNN：MSFA-Net；Transformer+ResNet-34：DEFI-Net；U-Net+Transformer：DCLA-Net；普通 conv+row-column conv：ESTAN）；DECLA-Net Table 1 显示「加第二条编码器」值 +0.47~+0.63 Dice，而两个融合模块合计只 +0.18~+0.22。**增益来自第二路信息源，不是容量**，F2 复制同构权重不产生新信息。

**新读到的两条对期望值不利的证据**（2026-10-24 补）：

- MBFF-Net（MICCAI 2021, LNCS 12905, pp.313–322, Table 1）：颈动脉斑块的「多分支」是**同一编码器每层内的三支**（多尺度 / 多上下文空洞 / 颈动脉壁先验仿射调制），不是双编码器；三支全开 0.666→0.736 Dice，但相对 DenseUNet 只 +0.002（Table 2，0.778→0.780）。
- MS-Net（ISBI 2021, DOI 10.1109/ISBI48211.2021.9434157, Table 1）：唯一「同一图像两个分辨率视图 + 双分支」先例，分支异构（W-Unet vs ResNet-50+BFF），融合只是**逐元素相加**；相对最好的单支只 +0.008（LV 0.9439→0.9522）/+0.003（LA 0.9027→0.9061）。
- 结论：**把 E1（C3 进单编码器）当门槛实验，跑不动就不该继续堆双支路。**

## D4 融合：跨支门控为主，跨注意力只在 D 层

尺度定义（`features` 来自 R50 patch embedding，顺序与 `DecoderCup` 的 skip 使用一致）：

| 级别 | 分辨率 | 通道 | 来源 |
|---|---|---|---|
| 浅 S | 112×112 | 64 | `features[2]` |
| 中 M | 56×56 | 256 | `features[1]` |
| 深 D | 28×28 | 512 | `features[0]` |
| 瓶颈 B | 14×14 | 768 | ViT 输出 |

**主模块：跨支门控（每级独立一组，主支 A、辅支 B）**

```
ω_A = σ(Conv7x7([AvgPool(F_A); MaxPool(F_A)]))      # A 自己的空间注意力
ω_B = σ(Conv7x7([AvgPool(F_B); MaxPool(F_B)]))
F_A' = F_A + γ_A · (F_A ⊙ ω_B)                       # 用对方的权重门控自己
F_B' = F_B + γ_B · (F_B ⊙ ω_A)
```

- `γ` **零初始化** → 第 0 步严格等价 baseline，失败时不会比 A0 更差。
- 只在 D 层额外叠一次全 token 跨注意力（Q 本支、K/V 对方），S/M 层不做。
- 依据：DEFI-Net Table 4，GLIL（用对方注意力图交叉调制）单独 +1.66 Dice / HD95 24.17→18.45，而 GLFF（concat + 通道注意力）只 +0.67 / −4.96。
- 期望形态：**主要改善 HD95/ASSD 而不是 Dice**，因此判定以边界指标为主（见 experiments.md 1.3）。

**对照与限制**

- E3 对照 = `concat + 1×1 回投影`（≈+1.2M 参数），用来区分「跨支交互」与「多一路特征」。
- AG（加性门控）与 CSA（通道+空间）保留为备选对照，不在 E 组排期内。
- 计算约束：56×56 全 token 注意力单次前向约 45 GFLOP，约为整模型 5 倍，**不可行**；S/M 只允许门控这类逐像素运算。
  - **2026-10-24 修订（见 D11.5）**：全 token 不行，但 **窗内注意力**（7×7 窗、每窗 49 token）可把成本降到约 1/64，S/M 层允许用 L3 档；这一条推翻了「S/M 只能门控」的旧限制。
- ⏸ **未排期候选：显式边界监督**。MBFF-Net Table 1 里 BPS（边界保留结构 + 边界损失）单项贡献 +0.044 Dice（0.736→0.780），比任何一个特征分支都大。若 E 组证明「堆融合模块」无效，先试这个，而不是继续加模块。

## D8 评估协议

- **划分**：病例级（`patient_key`），每子集独立，`seed=1234`、`test_ratio=0.2`，只有 train/test，**没有验证集、也不做 5-fold**（早期文档写过 5-fold，已作废）。
- **两个子集分开**：SPARC 与 Zhongnan 各自训练、各自测试，不混合、不跨设备合并统计。
- **epoch**：先用 `--eval_test_every 5/10` 跑出 test 曲线，挑一个整数 epoch 冻结，之后所有变体复用（CLAUDE.md 第 8 条）。报告里必须写明「epoch 选自测试曲线」这一限制。
- **指标**：Dice、ASSD、HD95、DeltaArea（预测面积 − 真值面积，带符号）与 |DeltaArea|。
- **显著性**：按病例配对 Wilcoxon（同一病例多张切片先取均值再配对），p < 0.05；DeltaArea 只报均值，不做显著性。
- **必报**：Params / FLOPs / 单张推理时延。
- **不可对标**：公开颈动脉集 Dice 0.94–0.96 多为受试者泄漏下的乐观值（DCLA-Net：1100 张 / 11 人、随机 3:1:1），我们的病例级数字不应与它们直接比大小。

### D11.1 触发原因

A3（旧 WGA）无显著增益，附录 A.1 已列四条结构原因。本次讨论补充第五条，也是最根本的一条：**第二路喂了第一路已经吃过的东西**——主路吃 C1+C2+C3，侧路又只吃 C3。这不是「双骨干参数冗余」，而是「第二路没有新信息」。

同时修正一条此前表述错误：不能说「两条路输入重复」。小波子带是有损、有方向性的变换，LH/HL/HH 与 C1 不是同一份输入。真正冗余的只有 C3（能量图，丢了方向与符号）被两路共吃这一点。

### D11.2 输入契约（硬约束）

| 路 | 输入 | 来源 | 与另一路的重叠 |
|---|---|---|---|
| 主路 | **仅 C1**，复制成 3 通道 | `x[:, 0:1].repeat(1,3,1,1)` | 无 |
| 侧路 | **LH / HL / HH** 三个方向子带，各 1 通道，**上采样回 224²** | 对 `x[:, 0:1]` 做 1 级 Haar → 取三分量（各 112²）→ 双线性插值回 224² → 堆成 3 通道 | 无（方向+符号信息与 C1 不同） |

- **输入端不拼任何通道**：主路只吃 C1，侧路只吃子带；C2/C3 退出输入，仅保留为消融项。`build_three_channel` 的 3 通道拼法（A1/A3）不再用于主方案。
- **禁止**侧路读 C3：C3 是三者平方和的平方根，已丢弃方向与符号，且与侧路三子带信息重复。
- **禁止**侧路读 C1：低频与主路 C1 高度重合。
- **必须上采样回 224²**：1 级 DWT 输出是 112²，若直接喂 R50，`stem`（stride 4）会降到 28²，整条侧路比主路低两个层级，接点全对不上。
- 若要做「4 通道侧路」，第 4 通道只能是 C1 的 1/2 下采样再上采样，且必须作为独立消融，不混进主方案。

### D11.4 四个接点与接线图

接点沿用 D4 的尺度定义，但位置从「ViT 输出之后」前移到 R50 的各 stage 输出。**两个骨干按 stage 交错执行（interleaved），每级先各自出特征、再做双向融合，融合后的特征同时回到两条骨干继续往下走**——不是各自跑完再把侧路塞进 skip。

```
主路 C1 (B,1,224,224)→repeat 3ch        侧路 LH|HL|HH (B,3,224,224)，子带已上采样
        │                                        │
 MainStem conv7×7/s2 → 112²/64          SideStem conv7×7/s2 → 112²/64
        └──────────────► ★F1 双向 ◄─────────────┘
                     A1 112²/64 ─┬─► features[2]（skip）
                                 └─► maxpool s2 → MainBlock1 → 56²/256
                                                │
        ┌──────────────► ★F2 双向 ◄─────────────┘
        │            A2 56²/256 ─┬─► features[1]（skip）
        │                        └─► MainBlock2 → 28²/512
        │                               │
        └──────────────► ★F3 双向 ◄─────┘
                     A3 28²/512 ─┬─► features[0]（skip）
                                 └─► MainBlock3 → 14²/1024
                                     patch_emb 1×1 → 196×768 → 12×ViT Block
                                                │
                     ★F4 双向 ◄────────────────┘
                     │ A4 14²/768（= encoded）
                     ▼
             DecoderCup（3 Block，skip 已替换）
             → SegmentationHead → logits (B,2,224,224)
```

侧路对应阶段同步推进：

```
B1 112²/64 ─► SideDown1 → B2 56²/256 ─► SideDown2 → B3 28²/512 ─► SideDown3 → B4 14²/768
      ▲ 融合结果 B1'                    ▲ B2'                ▲ B3'                ▲ B4'
```

- **交错执行是硬要求**：若两条骨干各自跑完再融合，主路 block2/block3 从未见过侧路信息，融合只作用在 skip 上，本质仍是单向注入。交错后 `A2` 是在「已含侧路信息的 A1」上算出来的，融合真正进入了主路主干。
- ★F1/F2/F3 的输出**直接替换** `features[2]/[1]/[0]`，`DecoderCup.forward` 里的 `cat([up, skip])`（[vit_seg_modeling.py#L311-L317](file:///f:/code/MyPython/TransUNet/networks/vit_seg_modeling.py#L311-L317)、[#L365](file:///f:/code/MyPython/TransUNet/networks/vit_seg_modeling.py#L365)）无需改动，只要传入新 `features`。
- ★F4 的位置与 [wavelet_model.py#L107](file:///f:/code/MyPython/TransUNet/networks/wavelet_model.py#L107) 一致，仍在 12 层 ViT 之后。
- 形状全部对齐（64@112²、256@56²、512@28²、768@14²），**不改变分辨率、不新增位置**。
- 因 R50 的 `forward` 是整体封装的，交错执行需要拆开 stage 边界：`root` / `maxpool` / `block1` / `block2` / `block3` 逐个调用（`ResNetV2.forward` 内部顺序见 [vit_seg_modeling_resnet_skip.py](file:///f:/code/MyPython/TransUNet/networks/vit_seg_modeling_resnet_skip.py)）。不改原文件，在 `dual_encoder_model.py` 里复制这段 stage 循环。

### D11.5 融合算子分档（本次的核心升级）

| 档 | 方法 | 能否内容重组 | 224/112² | 56² | 28² | 14² |
|---|---|---|---|---|---|---|
| L0 | concat + 1×1 conv | 否 | 便宜 | 便宜 | 便宜 | 便宜 |
| L1 | SE / CBAM / 逐元素门控（A3 用的档） | **否**，只调幅度 | 便宜 | 便宜 | 便宜 | 便宜 |
| L2 | 全局跨注意力 | 是 | 爆 | 爆 | 可行 | 可行 |
| L3 | 窗内 / 可变形注意力 | 是 | 可行 | 可行 | 可行 | 可行 |
| L4 | 双骨干逐层 concat | 是 | 8GB 不允许 | — | — | — |

本方案的分配（**四个接点全部双向**）：

```
★F1 (112²,  64ch) → L3 窗内双向跨注意力，窗 8×8（14×14=196 窗，每窗 64 token）
★F2 ( 56², 256ch) → L3 窗内双向跨注意力，窗 7×7（ 8×8= 64 窗，每窗 49 token）
★F3 ( 28², 512ch) → L2 全局双向跨注意力（784 token）
★F4 ( 14², 768ch) → L2 全局双向跨注意力（196 token）
```

单向的前一稿作废：只让侧路给主路供 K/V，侧路本身不被改写，退化成 A3。

单元结构（设主路特征 A、侧路特征 B，均为 `B×C×H×W`）：

```
★F1 / ★F2（L3 窗内双向）
A ─► 1×1 ─► unfold(w) ─► Q_A ─┐
B ─► 1×1 ─► unfold(w) ─► K_B,V_B ─┴─► 窗内注意力 ─► fold ─► GN ─► ×γ_A ─► + A ─► A'
B ─► 1×1 ─► unfold(w) ─► Q_B ─┐
A ─► 1×1 ─► unfold(w) ─► K_A,V_A ─┴─► 窗内注意力 ─► fold ─► GN ─► ×γ_B ─► + B ─► B'

★F3 / ★F4（L2 全局双向）
A' = A + γ_A · GN( MHA(Q=A, K=V=B) )
B' = B + γ_B · GN( MHA(Q=B, K=V=A) )
```

- 两式可并行算，但**共享同一组 K/V 来源**：先用 A、B 各算一份 Q/K/V，再互喂，不要为两个方向各建一套独立投影（否则参数翻倍且无收益）。
- **GN 必须放在残差支路内**（`A + γ·GN(...)`），不能写成 `GN(A + ...)`；后者在 γ=0 时仍会归一化，破坏第 0 步等价性（附录 A.1 第 4 条就是这个错）。
- `γ_A/γ_B` 为标量，零初始化；同时把输出投影 `W_O` 做小方差初始化，双保险。
- **低成本替代（L1 双向门控，仅作对照 R6）**：

```
ω_B = σ(Conv7×7([AvgPool(B); MaxPool(B)]))      # 空间权重来自侧路
ω_A = σ(Conv7×7([AvgPool(A); MaxPool(A)]))      # 空间权重来自主路
A' = A + γ_A · (A ⊙ ω_B)
B' = B + γ_B · (B ⊙ ω_A)
```

- L1 只能调幅度、不能重组内容；但它是双向的，所以即便退化也不会重犯 A3「单向注入」的错。
- L3 与 L2 的差别只在「能不能看见全图」，**两者都能内容重组**；不要把它讲成「弱化版」。

开销（batch 6、fp16 估算）：

| 接点 | token 数 | 注意力 logits | QKV+O 参数（单方向） | 说明 |
|---|---|---|---|---|
| ★F1 | 12544（窗内 64/窗） | 6×8×196×64² ≈ 77 MB | 4·64² ≈ 16K | 全局注意力需 15 GB，必须开窗 |
| ★F2 | 3136（窗内 49/窗） | 6×8×64×49² ≈ 15 MB | 4·256² ≈ 262K | 开窗后几乎免费 |
| ★F3 | 784 | 6×8×784² ≈ 59 MB/方向 | 4·512² ≈ 1.05M | 可直接全局 |
| ★F4 | 196 | 可忽略 | 4·768² ≈ 2.36M | 可直接全局 |

- 双向合计新增约 **7.4M** 参数。两个方向复用同一份 Q/K/V 投影只省实现、不省参数（每个方向仍需 4C²）；真要吃紧就把 `d_k` 降到 `C/4`（每个方向 C²），总量降到 ≈1.8M，logits 同步降到 1/4。不要靠减接点省显存，否则又回到「单点融合」（R1 已证明信息量不足时收益有限）。
- 量化依据：MSFA-Net Table 4（PDF p.12）中「加第二路」+8.56 Dice，「加/换融合模块」只 +0.45~2.18 —— **第二路优先于融合算子**，这是选 A/B 而非继续堆模块的理由；但「第二路怎么接」决定它是真第二路还是装饰。

### A.1 旧 WGA（A3，2026-10-23）❌

实际做法：主支吃 C1+C2+C3，辅支只吃 C3，`WaveletBranch`（1→32→64→128→768，4 次 stride-2，约 0.9M）降到 14×14，`WaveletGuidedAttention`（`nn.MultiheadAttention` 单向 + 残差后 GroupNorm）在 **ViT 瓶颈**融合。

实测：A3 vs A0 的 Dice 差在 SPARC 为 −0.0005、Zhongnan 为 +0.0017，Dice/ASSD/HD95 的 Wilcoxon p 均 > 0.29，**无显著增益**。

失败原因（四条，均已在新方案中修正）：

1. 主支已含 C3，辅支又只吃 C3 → 两路信息高度冗余，没有第二路信息源；
2. 只在 14×14 瓶颈融合 → 高分辨率边界信息完全没用上；
3. 门控在本支内部算权重，不是「用对方的权重调制自己」，结构上不可能产生跨支交互；
4. 残差后接 GroupNorm 重置了尺度，且没有零初始化门控 → 无法保证起点等价 baseline。

### A.2 CGAF 主模块（2026-10-23 版 D4）❌ 降级为 D 层可选项

原方案把双向跨注意力（位置编码 + `scaled_dot_product_attention` + pre-LN）作为主模块。降级理由：DEFI-Net Table 4 表明「跨支交互」的收益主要来自**对方的注意力图**这一廉价调制，而全 token 跨注意力在 S/M 级算力不可行；因此主模块换成 D4 的跨支门控，跨注意力只在 D 层（784 token）作为加强项保留。

# 自己设计特征融合模块：从全项目实测结果反推的十条守则

> 2026-11-10 新建。证据出处：[results.md](../results.md) §5（R50 模块横评）、§6（WRMM 消融）、§7（弱骨干 UNet 臂）、
> [fusion-operators-explained.md](fusion-operators-explained.md)（算子横评）、[fgr-explained.md](fgr-explained.md)（FGR 深讲）。
> 只写有实验证据支撑的规则，每条给出处；没有证据的想法标"待验证"。

## 0. 一页版

一句话：**先喂真的频率内容，再用改写式通道轴算子，机器要轻、门要慎加、全链只留一个零；过门槛才算数。**
最强正信号：弱骨干上 FGR ΔDice +1.703 / ΔHD −0.168（双门槛全过）；最强单变量：K2 小波→拉普拉斯 +0.978 / −0.162。

## 1. 十条守则（每条 = 规则 + 证据 + 出处）

1. **先看骨干有没有空间，再谈模块。** 强预训练 R50（ImageNet21k）上 13 个公开/自研模块全部落在 ±0.3 噪声带
   （results.md §5）；弱骨干（随机初始化）上 FGR 拿到 +1.703（§7(4)）。增益来自"补回骨干丢掉的信息"，
   骨干特征饱和时什么模块都挤不出来（FDFUNet 频域模块在 R50 全灭，收益全在 UNet* 弱底座，§5 开头结论）。
2. **内容 > 结构，且要有判别性对照。** DDBE 换成普通特征（plain）→ +0.060≈噪声；真频带（Haar）→ +0.435（§5(12) vs (10)）。
   FGR 只喂频带内容+轻门控 → +0.305，与 DDBE 同级（§5(16)）。两条对照夹逼：**涨的是频率内容本身，不是"加了注意力机器"**。
   拿不准时做零输入对照（QKV 注意力喂全零仍涨 → 涨幅不来自内容，fusion-methods.md §3）。
3. **改写式 > 注入式。** 注入式（回贴不改写：FreqFusion、FEM、R-GEF、MREF、ABF +0.037）全判负；
   改写式（直接重写该点特征：DDBE、FGR）是唯一出稳定正信号的家族。挂载点选解码器各级输出。
4. **通道轴逐位置 > 空间轴注意力。** 逐位置 1×1 改写 + 逐通道门（FGR）有效；QKV 跨位置注意力的增益
   与输入内容无关（零输入对照）；"只调幅度"家族里逐像素 gate > 全局 MS-CAM（aff 五档垫底，
   fusion-operators-explained.md §3）。
5. **轻机器够用，重机器会互覆。** FGR 2.79M 拿到与 DDBE 9.26M 同级的信号（R50 上 +0.305 vs +0.435）；
   DDBE+FGR 同点串联反而比 FGR 单挂 −0.164（§5(17)）——同一点供给相同内容的多模块是信息冗余。
   要组合就换位置或换内容，弱骨干上才观察到小幅互补（+0.138，§7(4)）。
6. **门控有代价，默认全开起步。** K2 去门控 ΔDice +0.452（门控有害，表 6-C）；R50 RW_ng Dice −0.190 但 HD −0.018
   （表 6-A）。门控对 Dice 常是负资产；要用就 σ(bias=2)≈0.88 全开起步，且优先逐像素门而非全局门。
7. **一条链上只留一个零。** 唯一零点放最后的改写层（fuse 全零）；上游一切门/γ 的偏置必须非零
   （FGR gate bias=2.0）。两个零相乘梯度消失 = 模块永久关闭（教训：零初始化可能让模块实际被关闭，
   见 project_memory Lessons）。
8. **拉普拉斯幅值 > Haar 定向子带。** K2 上小波→拉普拉斯 +0.978 / −0.162 是全项目最强单变量（表 6-C）；
   方向无关的 4 邻域幅值 + 逐样本 z-score 比定向子带稳，且不做方向伪造（三个槽位共享同一幅值图）。
9. **换频率内容比换算子更值。** §6 全部留一臂里，唯一双改善的变量是频带定义（Haar→拉普拉斯）；
   算子形式（门/MLKM/挂法）带来的变化都在噪声带或为负。预算优先花在"喂什么"上。
10. **判定协议是硬约束。** 单 seed 噪声带 ±0.3 Dice；门槛 |ΔDice| ≥ 0.5 或 HD(medpy) 降 ≥ 0.1 mm；
    先整体验证、过门槛才追加拆分对照；HD 统一 medpy 口径不用 HD95（results.md 头注）。

## 2. 结论边界

- 十条守则全部来自 SPARC 单 seed 1234 + 同协议成对比较；跨数据集（Zhongnan）目前只有 DDBE-lap 一个方向一致证据（+0.506）。
- 守则 1/3/4 有多臂格局支撑但非同变量判别对照；守则 2/6/8 有同变量对照，最硬。
- 弱骨干组合互补（FGR+DDBE +0.138）在噪声带内，不作为设计依据。

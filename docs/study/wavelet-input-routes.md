# 小波高频信息怎么进入模型：三条路径

> 用途：把「小波图到底怎么算出来、又怎么送进网络」讲清楚。
> 依据：`networks/`、`datasets/` 当前实现。
> 日期：2026-10-25

---

## 0. 先给结论

同一张超声图，仓库里用三种不同方式把它的高频信息送进网络：

1. **三种图拼成三通道，一起进主网络**：原图、去噪重建图、高频能量图并排成 3 通道，第一层卷积就把它们混在一起；
2. **在第一种之上再加一条小支路**：输入仍是那三通道，但额外把「高频能量图」单独送进一条 4 层小卷积，在 14×14 处做一次注意力再回写主分支；
3. **只把三张方向子带图拼成三通道，喂第二条 ResNet-50**：主网络只吃原图，另一条骨干专吃高频方向信息，两条骨干在四个分辨率上逐级交换特征。

三者的输入图都不一样，不能互相解释。

```
一张归一化灰度图
   ├─ 原图 + 去噪重建图 + 高频能量图  → 3 通道 → 主网络入口
   ├─ 高频能量图                      → 4 层小卷积 → 14×14 做一次注意力
   └─ 水平/垂直/对角三张方向子带图     → 3 通道 → 第二条 ResNet-50 入口
```

## 1. 一张图从读盘到进网络，具体做了什么

### 1.1 读图与归一化

代码位置：[datasets/dataset_carotid.py](../../datasets/dataset_carotid.py)

1. 读 2D 切片（若意外是三维，取最后一维的中间层），标签按大于 0.5 二值化；
2. 训练时先做增强：90° 整数倍旋转、上下翻转、左右翻转、±15° 小角度旋转；
3. 按这张图自身 1% 与 99% 分位截断，再减均值除标准差（逐图统计，不是全数据集统计）；
4. 双三次插值缩放到 224×224，标签用最近邻。

得到的张量是 `(1, 224, 224)`。

### 1.2 小波分解怎么算

代码位置：[networks/wavelet.py](../../networks/wavelet.py)

- 用四个固定的 2×2 卷积核、步长 2，一次卷积就把图分成四张 112×112 的子图：
  - 一张**低频近似**（整体亮度轮廓）；
  - 三张**细节子带**：水平方向、垂直方向、对角方向，数值有正有负，代表该方向的边缘强度；
- 核系数固定为 0.5，**没有可学习参数**，不依赖第三方小波库；
- 逆变换只需把四张子带各自做转置卷积再相加，可原样还原。

举例：输入 224×224 → 四张 112×112。

### 1.3 由子带能造出哪三种图

1. **去噪重建图**：
   - 先把图平移到正数，再取对数（`log1p`），目的把超声的乘性斑点噪声变成加性；
   - 用三张细节子带的绝对值中位数估计噪声强度，算出阈值 `T = σ·sqrt(2 ln N)`；
   - 对细节子带做软阈值（小于阈值的部分直接压到 0），再逆变换、取指数还原；
   - 最后线性拉回到原图的均值与标准差量级。
2. **高频能量图**：三张细节子带逐像素平方求和再开方，得到一张 112×112 的强度图，标准化后双线性放大回 224×224。只取第一级分解。
3. **方向子带图**：直接把水平、垂直、对角三张细节子带各自标准化，再分别放大回 224×224。**不去噪、不求能量、不含低频**。

## 2. 路径一：三种图拼成三通道，一起进主网络

### 2.1 在哪里算

在数据加载的最后一步，CPU、逐样本执行，由训练参数 `--use_wavelet 1` 触发：

- 代码：[dataset_carotid.py](../../datasets/dataset_carotid.py) 的 `__getitem__` 末尾；
- 实现：[build_three_channel](../../networks/wavelet.py)；
- 输入 `(1, 224, 224)`，输出 `(3, 224, 224)`，三个通道依次是原图、去噪重建图、高频能量图。

训练集和测试集都传同一个开关（[trainer.py](../../trainer.py)），保证评估时输入构成一致。

### 2.2 怎么进网络

- 训练脚本在选择模型时，`--fusion` 保持默认 `none`，所以实例化的就是**原始 TransUNet**，没有新增任何模块（[train.py](../../train.py)）；
- 原网络只会在输入是单通道时把它复制成 3 份；这里是真正的 3 通道，所以直接透传；
- 入口的 7×7 卷积把 3 通道压成 64 通道，从此三张图不再有身份区别，网络自己学怎么加权。

**参数量与单通道基线完全一样**，差别只在第一层卷积看到的输入。

### 2.3 为什么这样效果有限

三张图都是原图的确定性函数，没有引入新信息；第一层卷积本来就能学出「原图加减高频」这类线性组合，所以「提前拼好」并不比让网络自己学多出什么。

---

## 3. 路径二：在那三通道之上，再单独喂一次高频能量图

### 3.1 输入没变

数据侧完全复用路径一：仍然是 `(3, 224, 224)`。

### 3.2 新增了什么

训练时加上 `--fusion cross`，模型换成 [WaveletTransUNet](../../networks/wavelet_model.py)，它在原 TransUNet 外面挂了两样东西：

1. **小卷积支路** `WaveletBranch`：4 个「3×3 卷积 + 批归一化 + 激活」，步长全为 2，通道 1→32→64→128→768，分辨率 224→112→56→28→14，约 0.9M 参数；
2. **小波引导注意力** `WaveletGuidedAttention`：LayerNorm → 4 头跨注意力 → 残差相加 → GroupNorm。

### 3.3 具体流程

```
输入 (B,3,224,224)
  ├─ 走原 TransUNet 主干 → 编码器输出 (B,196,768)，另有 28²/56²/112² 三个跳跃连接
  │         │
  │         └─ 还原成 (B,768,14,14)
  │                    ↑ Q
  └─ 只取第 3 通道（高频能量图）(B,1,224,224)
            └─ 小卷积支路 → (B,768,14,14)  ← K、V
                          │
              跨注意力后残差相加 + GroupNorm
                          │
                (B,768,14,14) → (B,196,768) → 原解码器 → 分割头
```

要点：

- 第 2 通道（去噪重建图）在融合阶段**完全不参与**，它只作为主网络入口的第 2 个通道；
- 融合只在 14×14 这一最低分辨率上做一次，其余层保持原样；
- 输入的「高频能量图」本身就是主网络入口的第 3 通道，所以这一步本质上是「拿高频图的可学习变换去注意高频图自己」。

把 `--use_wavelet` 关掉、只加 `--fusion cross`，就是一个对照：输入是原图复制三遍，支路看到的是原图而不是真实高频图，用来判断「注意力结构本身」有没有贡献。

## 4. 路径三：只把三张方向子带图拼成三通道，喂第二条 ResNet-50

### 4.1 数据侧只给单通道

训练时用 `--arch dual`，脚本会强制把 `--use_wavelet` 置 0，数据集只返回 `(1, 224, 224)`。小波改在模型内部算，GPU 上整批进行。

### 4.2 模型内部怎么分叉

代码位置：[networks/dual_encoder_model.py](../../networks/dual_encoder_model.py)

```
输入 (B,1,224,224)
  ├─ 原图复制成 3 通道 (B,3,224,224)          → 主路 ResNet-50 + Transformer
  └─ 同一张原图现场算方向子带 (B,3,224,224)   → 侧路 ResNet-50
```

方向子带的算法：

1. 平移到正数后取对数；
2. 一级小波分解，得到水平、垂直、对角三张 112×112 细节子带；
3. 每张子带**各自**减均值除标准差；
4. 各自双线性放大回 224×224，再拼成 3 通道。

与路径一的区别：**没有软阈值、没有逆变换重建、没有低频**，所以侧路只看到「有正负号的边缘方向强度」，与主路的原图尽量不重叠。

### 4.3 怎么进两条骨干

- 侧路骨干是标准 ResNet-50，入口卷积本身就是 `3→64`，所以三通道刚好对得上，不需要改第一层、也不需要复制通道；
- 两条骨干按阶段交错执行：各自先过入口卷积，在 112×112 融合一次；池化并过第一段残差后在 56×56 融合；第二段后在 28×28 融合；主路再单独走 Transformer 编码器，最后在 14×14 与侧路融合一次；
- 每次融合的结果会回灌两条骨干继续往下走，四个接点都是双向的（112²/56²/28² 并行双向，14² 串联双向：先更新侧路，主路再用更新后的侧路取 K/V）；
- 侧路可以复用主路同一份 ImageNet 预训练权重。

## 5. 三条路径对照

| 维度 | 路径一 | 路径二 | 路径三 |
|---|---|---|---|
| 小波在哪算 | 数据加载，CPU，逐样本 | 同路径一 | 模型前向，GPU，整批 |
| 送进什么 | 主网络入口，与原图混在一起 | 主网络入口 + 一条小卷积支路 | 第二条 ResNet-50 入口 |
| 通道内容 | 原图 / 去噪重建图 / 高频能量图 | 同路径一；支路只看高频能量图 | 水平 / 垂直 / 对角方向子带 |
| 是否去噪 | 是（软阈值 + 逆变换） | 是 | 否 |
| 是否含低频 | 是 | 是 | 否（侧路纯高频） |
| 融合位置 | 输入端 | 14×14 一次 | 112²、56²、28²、14² 四次 |
| 是否双骨干 | 否 | 否 | 是 |
| 额外开销 | 落在数据加载（单进程时直接拖慢每步） | 0.9M 参数 + 一次注意力 | 每步多一次对数、卷积、三次上采样、标准化 |

### 5.1 「水平 / 垂直 / 对角方向子带」是什么

它们是小波一次分解输出的三张**细节图**，每张只保留某一方向上的灰度变化，尺寸是原图的一半（224×224 → 112×112）。

原因是分解时并不看整张图，而是每次取一个 **2×2 的小块**，用四种不同的权重把这个块压成一个数（[networks/wavelet.py](../../networks/wavelet.py)）：

| 子带 | 2×2 权重 | 实际算的是 | 对什么敏感 |
|---|---|---|---|
| 低频近似 | 四个数都是 +0.5 | 四个像素求平均 | 整块的平均灰度，不含方向信息 |
| 水平方向 | 上排 +0.5，下排 −0.5 | **上下两排相减** | 竖直方向的灰度变化，即**水平走向的边界** |
| 垂直方向 | 左列 +0.5，右列 −0.5 | **左右两列相减** | 水平方向的灰度变化，即**竖直走向的边界** |
| 对角方向 | 左上、右下 +0.5；右上、左下 −0.5 | 两条对角线相减 | **斜向边界和角点** |

因为每 2×2 个像素只输出 1 个数，所以四张子带各是 112×112（原图四分之一像素），加起来与原图的像素总数相同，只是被拆成了「一个平均 + 三个方向差」。

放在颈动脉超声上，这三张图的直观含义是：

- **水平方向子带**：管腔与内膜之间那条近似横着的亮线、平躺的斑块表面，在这里最亮；
- **垂直方向子带**：管壁左右两侧、以及钙化后方声影的竖直边界，在这里最亮；
- **对角方向子带**：斑块的斜向纤维帽、不规则突起的拐角，在这里最亮。

两个必须注意的点：

1. **名字容易反着理解**：代码里「水平方向子带」是把上下两排相减，它检测的是水平走向的边，而不是水平方向的梯度。看代码或论文时先确认定义。
2. **数值有正有负**：正负号表示「由暗到亮」还是「由亮到暗」，所以不能像灰度图那样直接显示或直接送进网络，通常要先取绝对值、或按样本做标准化。路径三就是先把三张子带各自减均值除标准差再拼起来；路径一、二的第三通道则是把三张子带**平方求和再开方**，得到一张没有正负号的「高频能量图」，三张图被合成了一张。

一句话：**「水平 / 垂直 / 对角」描述的不是三种图像，而是同一张图在三个方向上的变化率**；三张合起来才是完整的高频信息。

### 5.2 「是否含低频」是什么意思

低频指小波一次分解得到的**低频近似**，也就是整块区域的灰度水平和大尺度轮廓（斑块整体偏亮还是偏暗、管腔和管壁的大致分界）。这一行问的是：**送到某一骨干入口的那组图里，有没有这部分信息**。

- 路径一、二：三通道里有原图和去噪重建图，两者都含低频，所以填「是」；
- 路径三：**侧路**的三通道只有水平/垂直/对角细节，既没有低频近似，也没有原图，所以填「否」；但同一次前向里主路仍然吃原图，所以「整张网络」并不缺低频，缺低频的只是侧路。

这一行的实际作用是区分两种设计意图：

| 侧路输入 | 信息关系 | 结果 |
|---|---|---|
| 含低频（路径一、二） | 与主路高度重叠 | 主路和侧路看到的东西差不多，融合的边际收益小 |
| 不含低频（路径三） | 与主路互补 | 侧路只提供方向性边缘，理论上能和主路的灰度信息互补 |

换句话说，「是否含低频」这一行是判断**两条输入是否冗余**的依据，而不是判断谁更好的依据。路径一、二之所以增益有限，一部分原因就写在它和「通道内容」这两行里：三张图都是原图的函数，又都含低频，信息高度重叠。

> 注意：表格里的「是 / 否」都只针对**该路径喂给网络的那组图**，不是对整张图像或整个模型而言。

---

## 6. 三个容易搞混的点

1. **「三通道」不等于同一种东西**：路径一的三通道含原图和去噪重建图，路径三的三通道只有方向子带。
2. **去噪重建图只在路径一、二存在**：路径三没有软阈值重建，不能用「去噪」去解释它的结果。
3. **小波在哪算影响耗时归因**：路径一、二的开销记在数据加载上，路径三记在每步前向上，两者的「每步耗时」不能直接对比。

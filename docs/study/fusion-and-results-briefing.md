# 融合方式、完整指标与文献页码（汇报底稿）

> 用途：向导师口头/书面汇报时的直接依据。
> 数据来源：本仓库 `metrics.csv` 实测（病例级）；代码以 `networks/`、`datasets/` 当前实现为准。
> 日期：2026-10-24

---

## 0. 一句话结论

**通过一个 4 层卷积的小特征提取模块，把 TransUNet 编码器的输出特征做加权；但融合比较少，只在最后一层做一次，不是真正的多路深度特征融合。**

展开说：当前实现**不是双骨干**，而是「三通道早融合 + 14×14 单点侧支跨注意力」。实测四项指标（Dice / ASSD / HD95 / DeltaArea）中，三组对比的 Dice、ASSD、HD95 **全部 p > 0.29，无一项显著**；唯一显著的是 SPARC 上从单通道原图基线到三通道早融合的 DeltaArea（p = 0.019），且方向为**面积更偏小**，即负向显著。这与文献中「加模块/加预处理收益极低」的结论方向一致。

## 1. 预处理做了哪些处理、融合具体怎么做的

### 1.1 每张图进网络前的全部处理

代码位置：[datasets/dataset_carotid.py](../datasets/dataset_carotid.py)

| 步骤 | 具体操作 |
|---|---|
| 1. 读取 | 读 nii，若为 3D 则取中间层 |
| 2. 标签 | `label > 0` 二值化 |
| 3. 增强（仅训练） | 90° 整数倍旋转、上下翻转、左右翻转、±15° 小角度旋转 |
| 4. 强度归一化 | **1%–99% 分位截断**，再对**该图自身**做 z-score（不是数据集统计量） |
| 5. 缩放 | 双线性缩放到 224×224 |
| 6. 三通道构造 | 仅 `--use_wavelet 1` 时执行，见 1.2 |

> 待核对：`docs/dataset.md` 写的是 ±20° 小角度旋转，代码是 `uniform(-15, 15)`，二者不一致，需统一。

### 1.2 三通道怎么来的

代码位置：[networks/wavelet.py](../networks/wavelet.py)

- **原图通道**：原图本身。
- **去噪重建通道**（对数域软阈值重建图）：
  1. 先把图平移到正数（`x - min + 1e-3`）；
  2. `log1p`，把超声的乘性斑点噪声转成加性；
  3. 一级 Haar 小波分解，得低频近似 / 水平方向子带 / 垂直方向子带 / 对角方向子带；
  4. VisuShrink 软阈值：`σ = MAD / 0.6745`，`T = σ · sqrt(2 ln N)`；
  5. 逆变换 → `expm1`；
  6. 再线性拉回原图通道的均值/标准差量级。
- **高频能量通道**：三个方向子带的能量 `sqrt(水平方向子带² + 垂直方向子带² + 对角方向子带²)` → z-score → 双线性插值回 224。

Haar 小波用固定的 2×2 卷积核实现，**无参数、不依赖第三方库**。只做一级分解，且当前没有 `layout` / `detail_level` 开关。

### 1.3 融合具体怎么做的

代码位置：[networks/wavelet_model.py](../networks/wavelet_model.py)

1. **输入层早融合**：原图通道 / 去噪重建通道 / 高频能量通道直接 `cat` 成 3 通道，一次性送进**同一个** R50 stem（7×7/2 卷积 + maxpool + 3 个 ResNet stage）→ ViT-B/16，得到 14×14×768 的 token。**只有一套权重，不存在第二套骨干。**
2. **唯一的显式融合模块 `WaveletGuidedAttention`**，只在 14×14 上做一次：
   - 侧支输入是 `x[:, 2:3]`，**即只取高频能量通道这一路**；
   - `WaveletBranch`：4 个 `conv-bn-relu(stride=2)`，通道 1→32→64→128→768，输出 14×14×768，约 0.9M 参数；
   - Q = 主分支 token（LayerNorm 后），K/V = 侧支 token（LayerNorm 后），**4 头跨注意力**；
   - 输出 reshape 回 14×14，**残差加回主分支**，再 `GroupNorm(1, 768)`。
3. 之后走原样：decoder 拿 encoded + ViT 中间层 skip，1×1 分割头输出单通道 logits。

### 1.4 为什么这个结构本身就不该有明显增益

这不是「调参没调好」，而是结构性原因：

1. 去噪重建通道、高频能量通道都是原图通道的**确定性函数**，没有引入任何新信息，只是重新加权。
2. 三通道共用一个 stem，网络在第一层就能自己学出 3→64 的线性混合，侧支那点增量已被溶掉。
3. 侧支输入又是高频能量通道 —— 主分支第 3 通道本身，等于**用高频能量通道的可学习变换去注意它自己**，信息回路闭环。
4. 融合只做一次，且切在 **14×14（224/16）** 这个空间分辨率最低的层，而增益本该出现在边界 / HD95 上。
5. 没有第二路独立证据（不同模态、不同尺度、不同感受野），本质是「单路 + 一次重加权」。

### 读法（建议照此汇报）

- Dice / ASSD / HD95 三组对比**全部 p > 0.29**，任何一项目标指标都不显著。
- 唯一显著的是 SPARC 上从单通道原图基线到三通道早融合的 DeltaArea（p = 0.019），方向是**面积更偏小**。也就是说「加了小波」在这份数据上是**负向的显著**，而不是正向。
- 三通道＋小波引导注意力相对三通道早融合也没有带来任何显著变化（Dice p = 0.972 / 0.810），说明那层 14×14 跨注意力没有起作用，与 1.4 的结构分析一致。

### 三篇最关键的「反证」（一句话版）

1. **MBFF-Net**：把能想到的都加了（三分支 + 先验边界检测网 + BPS），最终只比 DenseUNet 高 **0.002 Dice**（Table 1/2，p.319）——说明「堆模块」在超声斑块上收益极低。
2. **去噪 benchmark**：133 例、22 种方法，Friedman p = 0.5636（Table A1，p.22），原文明确写没有一种去噪能在统计上赢过原图（p.13）——直接支撑「预处理增益不高」。
3. **MSFA-Net**：把第二路「恢复」进来值 +8.5 Dice，但融合模块本身只值 +0.45~2.18（Table 4，p.12）——支撑「收益来自第二路信息源，不来自融合模块」。

## 4. 汇报口径总结

**我们的融合是「三通道早融合 + 14×14 单点侧支」，不是双骨干；实测四项指标无一显著（p > 0.29），唯一显著的 DeltaArea 还是负向（p = 0.019）；这与 MBFF-Net 只 +0.002、去噪 benchmark p = 0.5636 的文献结论方向一致。真正有增益的是显式边界监督，那条线才是应该继续投入的方向。**

# 实验结果（全部为终点 epoch 200）

统一口径：所有模型训 200 epoch，取训练结束那一版权重（`epoch_199.pth`，权重名 0 基）在 SPARC 测试集（160 张切片）上的成绩；指标格式一律 **Dice% / ASSD mm / HD mm**，Dice 越大越好、ASSD/HD 越小越好；所有变体与 §1(1) 单骨干基线比，过幅度门槛 |ΔDice| ≥ 0.5% 或 HD 降 ≥ 0.1 mm 才作结论（判定规则见 [experiments.md](experiments.md) §1.9）。计划与状态见 [experiments.md](experiments.md) / [status.md](status.md)；2026-10-25 之前旧口径结果在 experiments.md §1.1。

距离指标口径：**HD = medpy `hd`**，最大表面距离，即论文 Table 1 报的 HD 口径（TransUNet 0.98±0.81）。HD 是全项目唯一的判定用距离指标，2026-11-01 起所有距离数字一律按 HD 报，不再并列其它版本。

高低频分离只有三种位置，下面每条都写明是哪一种：**输入级**（对输入图像做 1 级 Haar 小波——固定 2×2 核、无参数、log 域现算——得到低频图/高频"边缘图"/方向子带，当作输入图喂进网络）、**特征级**（对解码器中间特征图做 1 级 Haar 分低频/高频再处理）、**不碰频域**。

## 1. 3-seed 基线与双骨干（回答：双骨干比单骨干强不强？）

(1) **单骨干基线（TransUNet R50+ViT，全项目参照物）**。灰度原图 repeat 3 通道进网络，不碰频域。R50 卷积（局部）先提特征：三张中间特征图（112²/64、56²/256、28²/512）作 skip 留下，最深 14²/1024 特征经 1×1 卷积变成 196 个 token 交给 12 层 ViT（全局自注意力）处理。**两个模块的结合方式是串联 + 解码器拼接**：ViT 输出进解码器，解码器每一级把 R50 的 skip 特征拼接（cat 后接卷积）上来。没有跨支注意力。代码：[vit_seg_modeling.py](../networks/vit_seg_modeling.py#L446-L472)。
结果：s1234 = 90.32% / 0.1457 / 0.64；s2024 = 90.23% / 0.1490 / 0.66；s3407 = 90.40% / 0.1441 / 0.61；3-seed 均值 **90.32%**（HD 均值 0.64）。

(2) **双骨干·四级跨支注意力融合（旧代号 dual auto）**。主路 = (1) 的全套 R50+ViT，吃原图；侧路 = 一套独立的同构 R50（复用同一份 ImageNet21k 预训练权重），吃 LH/HL/HH 三个方向子带拼成的 3 通道图（输入级 Haar 分离，不含低频，与主路信息不重叠）。**两个骨干的融合用注意力机制、不是拼接**：编码过程在四个尺度（112²、56²、28²、14²）各设一个融合点，每点双向跨支注意力——主路特征当 Query、侧路特征当 Key/Value，输出经零初始化标量 γ 残差加回主路；对称地侧路也拿主路信息更新自己；融合结果各自继续下走。**解码器只接主路**，侧路特征从不进解码器。代码：[dual_encoder_model.py](../networks/dual_encoder_model.py#L338-L513)。
结果：s1234 = 90.46% / 0.1465 / 0.65；s2024 = 90.37% / 0.1459 / 0.67；s3407 = 90.12% / 0.1530 / 0.70；3-seed 均值 **90.32%**（HD 均值 0.67）。

读法：两者均值完全持平（HD 0.67 vs 0.64，同向）→ 双骨干无收益（判负）。seed 间波动约 ±0.3%，下面单 seed 差距小于此的都不可当结论。

## 2. 单 seed（1234）变体横评（回答：各改法谁能超过基线？）

(1) **单骨干基线**（参照物，同 §1(1)）：90.32% / 0.1457 / 0.64。

(2) **双骨干·逐像素门控（旧代号 dual gate）**：结构同 §1(2)，融合算子换成门控——把对方的通道均值+最大值空间图过 7×7 卷积和 sigmoid，逐像素乘到自己特征上（只调幅度、不交换内容），零初始化残差。90.24% / 0.1458 / 0.67。

(3) **双骨干·可变形大核（旧代号 dual deform）**：融合算子换成可变形卷积——自己降维后预测 k=5 采样偏移，在**对方**特征上做可变形大核卷积，双向。90.60% / 0.1421 / 0.61。

(4) **双骨干·MS-CAM 幅度调制（旧代号 dual aff）**：融合算子换成 AFF 式——两支相加过 MS-CAM（局部 1×1 支 + 全局池化支）得权重 m，A×m、B×(1−m)。90.35% / 0.1444 / 0.64。

(5) **输入级边缘图·单骨干（旧代号 edge）**：单骨干基线不变，stem 改吃 4 通道 = 原图 3 + 小波高频重建图 1（输入级 Haar、LL 置零重建的"边缘图"）；无融合模块。90.32% / 0.1457 / 0.61。
　边缘图与侧路"方向子带"的区别（同一个 Haar 分解的两种用法）：**边缘图做了 IDWT**——三个方向子带按固定 Haar 滤波系数线性叠加回空间域成 1 张图（等价于对原图做固定高通滤波，方向信息合并）；**方向子带不做 IDWT**——LH/HL/HH 各自上采样、独立成 3 通道（方向信息保留，由网络自己学组合）。

(6) **输入级边缘图·双骨干（旧代号 edgedual）**：§1(2) 双骨干 + 主路 stem 改吃 4 通道（原图 3 + 边缘图 1）。注意**不是「一个骨干吃原图、另一个吃边缘图」**——边缘图只拼进主路当第 4 个输入通道（主路同时看到原图+边缘图），侧路吃的是 LH/HL/HH 三个方向子带（不是边缘图）；骨干间仍是四级跨支注意力融合。**90.74%** / 0.1395 / 0.63。

(7) **输入级边缘图·双骨干·可变形大核（旧代号 edgedeform）**：同 (6)，融合算子换成可变形大核。90.60% / 0.1410 / 0.61。

(8) **解码器四级 DDBE（旧代号 ddbe4）**：单骨干基线，不加侧路；高低频分离在**特征级**——解码器四级输出各挂一个 DDBE 模块，对每级特征图做 1 级 Haar 分出高频支（LH/HL/HH）、低频支（LL）、上下文支，三支**拼接**后 1×1 卷积（零初始化）经 CBAM 残差加回。90.31% / 0.1442 / 0.64。

(9) **解码器四级 DDBE + ACAM（旧代号 ddbefull，BDFR-Net 完整版）**：(8) 再加 ACAM——解码器每级把 skip 特征与当前解码特征做跨级语义对齐后重写 skip，再进原拼接。90.65% / 0.1418 / 0.61。

(10) **双骨干·主路吃 LL 低频图（旧代号 mainLL，XNet 式搭车）**：§1(2) 双骨干不变，主路输入换成 LL 低频图（输入级 Haar 的低频子带上采样回 224²）——主路只看低频，高频信息全在侧路方向子带。90.39% / 0.1478 / 0.65。

读法：方向为正的排序 (6) 90.74% > (9) 90.65% > (3)(7) 90.60% > 基线 90.32%；HD 口径同向（(3)(7)(9) 0.61 < (6) 0.63 < 基线 0.64），deform 在 Dice/HD/ASSD 三项上都最靠前；均为单 seed 方向证据，不作结论。

## 3. 先行诊断（小网络门槛实验，非正式训练）

(1) **边缘通道信息增量**：小型分割网络对比「仅原图」与「原图 + 边缘图第 4 通道」两组输入（输入级 Haar 分离，无融合模块），看 Dice 差值：SPARC **+1.81%**，Zhongnan **+1.83%**。
读法：边缘图确实带信息；但正式大网络（§2(5)(6)）没把这部分信息变成过线收益。

## 4. 文献复现三网络（seed1234 / SPARC / from scratch，epoch 200）

> 三者均从头训练（无预训练可载），且都比 TransUNet 基线低约 4 个点——骨干家族差异（纯卷积 vs Transformer 预训练），**只在复现线内部互比**。

(1) **纯卷积 U-Net**：单支卷积编码-解码 + skip 拼接，不碰频域。60.3M。86.55% / 0.2250 / 1.14（92 min）。

(2) **XNet（ICCV2023，双输出取低频主支，bs2+ga4）**：输入级 Haar 分离成两张图——LF 图（LL 子带上采样）与 HF 图（LL 置零重建）；低频/高频两支各自独立编码，中间 **X 形交叉融合**，双解码器出双输出，评估取低频主支。326.2M。87.06% / 0.2122 / 1.11（274 min）。

(3) **GobletNet（TMI2025，λ=0.3）**：**双支 CNN 编码器**（均 ResNet 式 BasicBlock，from scratch 无预训练）：语义支吃原图，高频支吃 H = HL+LH+HH+0.3·LL（输入级 Haar 现算；论文离线 pywt db2 → 本复现 Haar，已记录偏离）；两支在 l1-l4 每级经 **FAM 互标定**（cat 两支特征 → 两路 sigmoid 空间注意力各自乘回本支），FAM 输出既送下一级也当解码 skip；最深两支 cat 融合；解码器每级 cat[上采样, 两支 FAM 输出]。133.3M。86.28% / 0.2287 / 1.22（149 min）。

(4) **GobletNet 复现·λ=0（高频支 H = HL+LH+HH，不回灌 LL）**：结构同 (3)，只把 `--hf_lambda` 从 0.3 置 0。87.15% / 0.2092 / HD95 0.6919（145 min）。相对 (3) 的 λ=0.3 版 Dice **+0.87**、ASSD −0.020；**HD 不可直接比**——(3) 的旧快照 `test_curve.csv` 只有 5 列（无 hd95），表里的 1.22 是 medpy `hd` 口径，本节 (4) 是 HD95。

读法：XNet 比同底座 U-Net 高约 0.5%（方向为正、不作结论），HD 同向（1.11 < 1.14）；GobletNet 原版 λ=0.3 最差（HD 1.22），**把 λ 置 0 后回升到 87.15（相对 U-Net +0.60、与 XNet 87.06 持平），说明原配置里 0.3 的 LL 回灌是负资产**——高频支一旦拿到低频能量就会退化成第二个语义支，FAM 互标定失去意义。GobletNet 垫底是方法与数据不匹配，不是复现问题（端口逐行对照官方，偏离项论文自证影响小）：它的设计标准来自电镜 EM——无散斑噪声、边界=锐利高频响应，假设「瓶颈只在高频细节」；颈动脉超声里高频子带被乘性斑点噪声主导、斑块边界是低对比度渐变，独立高频编码支补进来的是噪声（原 λ=0.3 配置参数 133M 为 U-Net 的 2 倍仍倒退，排除容量因素；λ=0 版虽追平 XNet，仍只是把高频支还原成第二个普通编码支，没有拿到任何超出同底座 U-Net 的净增益）。这与本项目证据一致：边缘图喂大主干零增益（§2(5)）；同域的 BDFR-Net 涨点靠的是特征级解耦+门控，不是输入端再开高频骨干。

读法（以 11-14 补跑的 FGREnc 为准，**推翻当日基于 3 臂的「越靠近输出越好」**）：**主链（编码器或解码器）≈ +1.7~2.1，skip 副本 +1.2，跨尺度编码器融合 +0.9**。FGREnc 88.62 与 dec 88.2484 只差 **0.37（< 0.5 判定线）**，即**编码器与解码器两个位置不可分辨**；唯一能分开的是 skip——它比两条主链低 0.5~0.9。机制解释随之改变：决定增益的是「改写是否落在主链上」（改写后的特征还能被后续卷积与梯度继续使用），而不是离输出端多远；只改 skip 副本等于把编码器特征截断在拼接口上，解码器无法回头修编码器。限定：①enc 与 dec 都是单 seed，0.37 只能记「并列」不能排序；②EFF 与 FGR 内容不同（跨尺度 lf），enc/dec 的可比性只在 FGR 内部成立。

**FGREnc 失败原因（与模块无关）**：ep5 评测时崩在 `_eval_test`，`AttributeError: 'CarotidDataset' object has no attribute 'weights'`。`datasets/dataset_carotid.py` 在 13:30:53 被改成带样本权重表（新增 `self.weights` 与 `__getitem__` 的 weight 键，见 §8），而该 job 12:48 已启动；评测时新建的 DataLoader worker 重新导入新版类，主进程传入的仍是旧实例 → 旧实例没有这个属性。教训：**队列在跑时不能改会被 worker 重新导入的数据/模型文件**（FGRSkip 13:31 起跑，躲过了）。补跑 11-14 01:25→03:16（110.7 min，exit 0，`fgre_20261114_012516.log`）读数 **88.62 / 0.176 / HD 0.93 / HD95 0.56**，参数逐项与首跑一致（`fgr=1 fgr_pos=enc loss=ce_dice seed=1234 ep200`），是本批最高。

**EFF 与 EFF-v2（设计口径）**：EFF = `y = x + Fuse1x1(w ⊙ [hf(x), lf(ctx)])`，`ctx = Up(Conv1x1(deep))`，FPN 式自顶向下 `y4←(x4,x5) → y3 → y2 → y1` 作 skip，门只吃 `[x,ctx]` 的 DCT 谱描述子，fuse 零初始化恒等起步，+2.79M 与 FGR 逐位相等。补跑后与同位置、同参数的 FGREnc（88.62）差 **1.14 Dice**——**编码器位置本身不是瓶颈，差在内容**：EFF 的 lf 来自跨尺度 `ctx`，而 FGR 改的是自身 hf+lf 双带，前者把「别尺度的低频」塞进当前尺度，信息与自身低频高度共线。（历史上 MFDF/FEM/ABF/R-GEF 这些注入式编码器模块在 R50 与 U-Net 上全部判负，EFF 的 +0.935 仍是编码器侧融合的最好读数，但已确认不是位置问题。）EFF-v2 因此只动内容与投影：`--eff_mode band` 两枚 C→C 零核并联修串带（+960 参数）、`--eff_lfdiff 1` 把 lf 换成 `LL(ctx)−LL(x)` 剔掉共线部分（无新增参数），冒烟已全绿，未入队。

## 9. 距离指标（ASSD / HD）的误差结构（多 seed 集成只作内部诊断）

口径：R50-ViT-B_16（ImageNet21k 预训练，vit_layers=12）+ DecoderCup，SPARC 测试集 160 张切片，bs4/ga2、200 epoch、终点 `epoch_199.pth`，seed 1234/42/317/1029/3407。全部为复用现成 checkpoint 的评测，**不训练**。

### 9.1 误差结构诊断（2026-11-14）

- **HD 尾部是整段局部错位，且两个方向近似对称**：160 例中 108 例由 GT→pred（漏检）侧决定 HD、52 例由 pred→GT（多检）侧决定；高 HD 组（≥p75）miss_max 1.098 mm vs extra_max 1.049 mm，每例距离 >5 px 的缺失像素约 96 个。因此只压「远处假阳性」最多覆盖约 1/3 的尾部，漏检侧必须同时约束。
- **评测后处理无效**：在缓存的 224² 概率图上比较现行二值 nearest 回原网格、概率双线性回原网格再阈值、概率高斯 σ=1、二值 3×3 中值等 5 种口径，ASSD 与 HD 的变化均 ≤0.001 mm。预测连通域数 158/160 例为 1，连通域清理同样无空间。
- **seed 噪声构成 HD 尾部的重要来源**：单模型 HD 0.614–0.719（sd 0.039）；逐例 seed 内 sd 均值 0.145 mm，高 HD 组 0.318 mm（占其均值 26%）；若每例取最好 seed，HD 0.658→0.490。说明当前 0.02–0.05 mm 的单 seed HD 差异不足以支撑结论。

### 9.2 5 seed 概率集成（仅内部诊断，**不作论文口径**）

> 定位（2026-11-14 用户决策）：5-seed 概率集成只是诊断工具，用来估计 seed 噪声与「难例能否靠多模型平均消掉」，**不作为论文方法、也不作为论文报数口径**。论文里的成绩一律报单 seed 配对结果；过门槛的臂再按 3 seed（42/317/1029）复核，报均值±sd。

集成方式：5 个同协议 checkpoint 逐像素 softmax 概率平均后再 argmax，见 [scripts/eval_carotid.py](../scripts/eval_carotid.py) 的 `--ens_ckpts`。

| 臂 | Dice% | ASSD | HD | ΔDice | ΔASSD | ΔHD |
|---|---|---|---|---|---|---|
| 5 seed 单模型（均值±sd） | 90.34±0.07 | 0.147±0.002 | 0.66±0.04 | — | — | — |
| 5 seed 概率集成 | 90.89 | 0.137 | 0.59 | +0.55 | −0.0098 | −0.064 |

读法：集成把 HD 从 0.658 压到 0.595（−9.7%）、ASSD 降 6.7%、Dice 过 +0.5 门槛；HD 降幅 −0.064 mm 未到 0.1 mm 有效线。集成成绩与单 seed 结构臂的最好点（双骨干 frc_fds 90.80/0.1387/0.5952、四级 DDBE+ACAM 90.65/0.1418/0.6074）持平或更优，且完全不含新模块——**现有单 seed 结构增益（HD −0.02~−0.05）处在 seed 噪声内**。剩余 HD 与 best-of-seed 下界（0.490）仍差约 0.10 mm，属系统性局部误差，需从「原分辨率证据」或「漏检侧尾部损失」入手，不能再靠评测/后处理。

**(a) 量化地板**。把 GT 走一遍「原网格 → S×S → 原网格」的往返（`ndi.zoom` order=0，与预测同一条路），在 SPARC 测试集 160 例上测该分辨率下不可再降的下限：

| GT 往返 @320 | 99.96 | 0.0007 | 0.0102 | 0.0045 |
| GT 往返 @384 | 99.99 | 0.0002 | 0.0043 | 0.0020 |

读法：**量化地板可以忽略（0.003 / 0.032），提高输入分辨率或换学习式上采样都无空间**（对应 [venue-survey.md](venue-survey.md) §14 的 #88，可划掉）。实测 ASSD 0.146 ≈ 2.8 个「1 px 台阶」，HD 0.705 ≈ 5.4 个台阶——误差是真实的边界定位误差，不是网格台阶。

**(b) HD 尾部与斑块面积强相关**。逐例 GT 面积（原网格像素，中位数 4058，范围 519–16878）与 5 seed 平均 HD 的 Spearman ρ = **0.641（p < 1e-15）**；HD 最高的 10 例面积 3873–16878 px，占切片 5.7%–17.9%。HD 是「整条边界上最坏的一处」，大斑块边界更长、给出一次大错的机会更多。这解释了为什么均匀重加权类损失动不了 HD：它改的是平均梯度，不是最坏点。

- **稳定难例**（损失改不动）：593761_0508 2.16/sd 0.21、569_1126-5 1.89/0.10、227048_0319 1.46/0.21；
- **随机崩例**（方差缩减才管用）：170040_1810 4.29/sd 1.95（2.63↔7.11）、495_1008 3.88/sd 2.49（1.08↔5.71）、569_1126-6 2.97/sd 1.63。

**(e) 难例审计扩到 40 例（2026-11-14，零训练）**。按 5 seed 平均 HD 排序取前 40，覆盖 30 例 persistent 全部、占全部 HD 的 **47.0%**（前 10 例占 20.0%）。逐例同时记录集成预测（5 ckpt 概率平均后 argmax）与 GT 形态，清单 `Temp/hard_cases.csv`，叠加图 40 张 `Temp/hard_cases/*.png`（绿=GT、红=预测、黄=重合），汇总页 `Temp/hard_cases/review.html`。

审计结论四条（逐例机制表 `Temp/hard_case_diag.csv`：HD 最坏点坐标与朝向、该点图像梯度、预测孤立块面积）：

1. **标注没有系统性缺陷**。40 例 GT 全部单连通（全体 160 例也无多连通块），只有 1 例带 2 px 孔洞（可忽略；全体 3 例有孔洞）；仅 3 例触及图像边界（全体 5 例）。GT 面积中位 6804 px（全体 4058），16 例 ≥8000 px、8 例 <4000 px——既不是清一色小斑块，也不是清一色大斑块。
2. **面积误差变大，方向平衡**。40 例 |Δarea| 中位 **13.2%**（全体 160 例 6.2%），±10% 之外各 12 例；HD 朝向与面积方向一致——gt→pred 24 例（预测少覆盖，rel 中位 −4.8%）、pred→gt 15 例（多覆盖，+7.1%）。一半少一半多，没有单向偏置。HD/ASSD 比值中位 **5.35**（3.2–13.7）：最坏一点比平均错位远 5 倍以上。
3. **不是「没边可循」，是「有强边却贴错」**。GT 整条轮廓上的平均 |∇I|（按图像 99 分位归一化）在难例与非难例间没有差别（**0.392 vs 0.389**，与集成 HD 的 ρ = −0.075；GT 内外对比度同样无关，ρ = 0.037）。但把 HD 的**最坏点**单独取出来：39 例无 FP 块的病例里该点梯度中位 **0.48**，17/39 ≥0.6，15 例大斑块（≥8000 px）中位 **0.73**——都高于 GT 整条轮廓的平均 0.39。难例崩在**高梯度处**（厚亮带/强回声界面），不是在看不见的地方。
4. **尾部两类，比例极不均衡**：
   - **孤立假阳性块只有 1/40**（#2 331495_1008-3，329 px），但它的 HD 是 **5.46**，而其余 39 例 HD 中位只有 **1.03**。这一例是纯随机崩例（5 seed 1.08–5.71，argmax 集成反而放大到 5.46）。
   - **其余 39 例 HD 0.4–2.2**：最坏点落在强边缘，面积差 ±10% 各 12 例，超/欠覆盖方向与 HD 朝向一致 → 亮带两侧的口径分歧。目视 4 例佐证：#4 593761（HD 2.15，面积 −17%，最坏点 grad 0.67）、#9 501099（1.43，+44%，0.68）、#1 170040（3.90，−3%，0.97，GT 沿强回声带有一段细长延伸没跟出去）、#2 331495（FP 块）。

由此把 (d) 的结论再收一格：**39/40 是「强边上贴错位置」的稳定型错误——跨 seed 稳定，且对已试过的像素重加权类损失不敏感（两条边都给低损失）；极端尾部（HD 5 以上）只有 1 例，是孤立假阳性块，属随机崩例**。这一类错误需要的不是「再给某个像素加权」，而是直接对两侧距离剖面回传——对应 §10 的 #82；翻转 TTA 已实测无效、禁用。

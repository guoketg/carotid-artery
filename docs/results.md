# 实验结果（全部为终点 epoch 200）

统一口径：所有模型训 200 epoch，取训练结束那一版权重（`epoch_199.pth`，权重名 0 基）在 SPARC 测试集（160 张切片）上的成绩；指标格式一律 **Dice% / ASSD mm / HD mm**，Dice 越大越好、ASSD/HD 越小越好；所有变体与 §1(1) 单骨干基线比，过幅度门槛 |ΔDice| ≥ 0.5% 或 HD 降 ≥ 0.1 mm 才作结论（判定规则见 [experiments.md](experiments.md) §1.9）。计划与状态见 [experiments.md](experiments.md) / [status.md](status.md)；2026-10-25 之前旧口径结果在 experiments.md §1.1。

距离指标口径：**HD = medpy `hd`**，最大表面距离，即论文 Table 1 报的 HD 口径（TransUNet 0.98±0.81）。HD 是全项目唯一的判定用距离指标，2026-11-01 起所有距离数字一律按 HD 报，不再并列其它版本。

高低频分离只有三种位置，下面每条都写明是哪一种：**输入级**（对输入图像做 1 级 Haar 小波——固定 2×2 核、无参数、log 域现算——得到低频图/高频"边缘图"/方向子带，当作输入图喂进网络）、**特征级**（对解码器中间特征图做 1 级 Haar 分低频/高频再处理）、**不碰频域**。

## 1. 3-seed 基线与双骨干（回答：双骨干比单骨干强不强？）

(1) **单骨干基线（TransUNet R50+ViT，全项目参照物）**。灰度原图 repeat 3 通道进网络，不碰频域。R50 卷积（局部）先提特征：三张中间特征图（112²/64、56²/256、28²/512）作 skip 留下，最深 14²/1024 特征经 1×1 卷积变成 196 个 token 交给 12 层 ViT（全局自注意力）处理。**两个模块的结合方式是串联 + 解码器拼接**：ViT 输出进解码器，解码器每一级把 R50 的 skip 特征拼接（cat 后接卷积）上来。没有跨支注意力。代码：[vit_seg_modeling.py](../networks/vit_seg_modeling.py#L446-L472)。
结果：s1234 = 90.32% / 0.1457 / 0.64；s2024 = 90.23% / 0.1490 / 0.66；s3407 = 90.40% / 0.1441 / 0.61；3-seed 均值 **90.32%**（HD 均值 0.64）。

(2) **双骨干·四级跨支注意力融合（旧代号 dual auto）**。主路 = (1) 的全套 R50+ViT，吃原图；侧路 = 一套独立的同构 R50（复用同一份 ImageNet21k 预训练权重），吃 LH/HL/HH 三个方向子带拼成的 3 通道图（输入级 Haar 分离，不含低频，与主路信息不重叠）。**两个骨干的融合用注意力机制、不是拼接**：编码过程在四个尺度（112²、56²、28²、14²）各设一个融合点，每点双向跨支注意力——主路特征当 Query、侧路特征当 Key/Value，输出经零初始化标量 γ 残差加回主路；对称地侧路也拿主路信息更新自己；融合结果各自继续下走。**解码器只接主路**，侧路特征从不进解码器。代码：[dual_encoder_model.py](../networks/dual_encoder_model.py#L338-L513)。
结果：s1234 = 90.46% / 0.1465 / 0.65；s2024 = 90.37% / 0.1459 / 0.67；s3407 = 90.12% / 0.1530 / 0.70；3-seed 均值 **90.32%**（HD 均值 0.67）。

读法：两者均值完全持平（HD 0.67 vs 0.64，同向）→ 双骨干无收益（判负）。seed 间波动约 ±0.3%，下面单 seed 差距小于此的都不可当结论。

## 2. 单 seed（1234）变体横评（回答：各改法谁能超过基线？）

(1) **单骨干基线**（参照物，同 §1(1)）：90.32% / 0.1457 / 0.64。

(2) **双骨干·逐像素门控（旧代号 dual gate）**：结构同 §1(2)，融合算子换成门控——把对方的通道均值+最大值空间图过 7×7 卷积和 sigmoid，逐像素乘到自己特征上（只调幅度、不交换内容），零初始化残差。90.24% / 0.1458 / 0.67。

(3) **双骨干·可变形大核（旧代号 dual deform）**：融合算子换成可变形卷积——自己降维后预测 k=5 采样偏移，在**对方**特征上做可变形大核卷积，双向。90.60% / 0.1421 / 0.61。

(4) **双骨干·MS-CAM 幅度调制（旧代号 dual aff）**：融合算子换成 AFF 式——两支相加过 MS-CAM（局部 1×1 支 + 全局池化支）得权重 m，A×m、B×(1−m)。90.35% / 0.1444 / 0.64。

(5) **输入级边缘图·单骨干（旧代号 edge）**：单骨干基线不变，stem 改吃 4 通道 = 原图 3 + 小波高频重建图 1（输入级 Haar、LL 置零重建的"边缘图"）；无融合模块。90.32% / 0.1457 / 0.61。
　边缘图与侧路"方向子带"的区别（同一个 Haar 分解的两种用法）：**边缘图做了 IDWT**——三个方向子带按固定 Haar 滤波系数线性叠加回空间域成 1 张图（等价于对原图做固定高通滤波，方向信息合并）；**方向子带不做 IDWT**——LH/HL/HH 各自上采样、独立成 3 通道（方向信息保留，由网络自己学组合）。

(6) **输入级边缘图·双骨干（旧代号 edgedual）**：§1(2) 双骨干 + 主路 stem 改吃 4 通道（原图 3 + 边缘图 1）。注意**不是「一个骨干吃原图、另一个吃边缘图」**——边缘图只拼进主路当第 4 个输入通道（主路同时看到原图+边缘图），侧路吃的是 LH/HL/HH 三个方向子带（不是边缘图）；骨干间仍是四级跨支注意力融合。**90.74%** / 0.1395 / 0.63。

(7) **输入级边缘图·双骨干·可变形大核（旧代号 edgedeform）**：同 (6)，融合算子换成可变形大核。90.60% / 0.1410 / 0.61。

(8) **解码器四级 DDBE（旧代号 ddbe4）**：单骨干基线，不加侧路；高低频分离在**特征级**——解码器四级输出各挂一个 DDBE 模块，对每级特征图做 1 级 Haar 分出高频支（LH/HL/HH）、低频支（LL）、上下文支，三支**拼接**后 1×1 卷积（零初始化）经 CBAM 残差加回。90.31% / 0.1442 / 0.64。

(9) **解码器四级 DDBE + ACAM（旧代号 ddbefull，BDFR-Net 完整版）**：(8) 再加 ACAM——解码器每级把 skip 特征与当前解码特征做跨级语义对齐后重写 skip，再进原拼接。90.65% / 0.1418 / 0.61。

(10) **双骨干·主路吃 LL 低频图（旧代号 mainLL，XNet 式搭车）**：§1(2) 双骨干不变，主路输入换成 LL 低频图（输入级 Haar 的低频子带上采样回 224²）——主路只看低频，高频信息全在侧路方向子带。90.39% / 0.1478 / 0.65。

读法：方向为正的排序 (6) 90.74% > (9) 90.65% > (3)(7) 90.60% > 基线 90.32%；HD 口径同向（(3)(7)(9) 0.61 < (6) 0.63 < 基线 0.64），deform 在 Dice/HD/ASSD 三项上都最靠前；均为单 seed 方向证据，不作结论。

## 3. 先行诊断（小网络门槛实验，非正式训练）

(1) **边缘通道信息增量**：小型分割网络对比「仅原图」与「原图 + 边缘图第 4 通道」两组输入（输入级 Haar 分离，无融合模块），看 Dice 差值：SPARC **+1.81%**，Zhongnan **+1.83%**。
读法：边缘图确实带信息；但正式大网络（§2(5)(6)）没把这部分信息变成过线收益。

## 4. 文献复现三网络（seed1234 / SPARC / from scratch，epoch 200）

> 三者均从头训练（无预训练可载），且都比 TransUNet 基线低约 4 个点——骨干家族差异（纯卷积 vs Transformer 预训练），**只在复现线内部互比**。

(1) **纯卷积 U-Net**：单支卷积编码-解码 + skip 拼接，不碰频域。60.3M。86.55% / 0.2250 / 1.14（92 min）。

(2) **XNet（ICCV2023，双输出取低频主支，bs2+ga4）**：输入级 Haar 分离成两张图——LF 图（LL 子带上采样）与 HF 图（LL 置零重建）；低频/高频两支各自独立编码，中间 **X 形交叉融合**，双解码器出双输出，评估取低频主支。326.2M。87.06% / 0.2122 / 1.11（274 min）。

(3) **GobletNet（TMI2025，λ=0.3）**：**双支 CNN 编码器**（均 ResNet 式 BasicBlock，from scratch 无预训练）：语义支吃原图，高频支吃 H = HL+LH+HH+0.3·LL（输入级 Haar 现算；论文离线 pywt db2 → 本复现 Haar，已记录偏离）；两支在 l1-l4 每级经 **FAM 互标定**（cat 两支特征 → 两路 sigmoid 空间注意力各自乘回本支），FAM 输出既送下一级也当解码 skip；最深两支 cat 融合；解码器每级 cat[上采样, 两支 FAM 输出]。133.3M。86.28% / 0.2287 / 1.22（149 min）。

(4) **GobletNet 复现·λ=0（高频支 H = HL+LH+HH，不回灌 LL）**：结构同 (3)，只把 `--hf_lambda` 从 0.3 置 0。87.15% / 0.2092 / HD95 0.6919（145 min）。相对 (3) 的 λ=0.3 版 Dice **+0.87**、ASSD −0.020；**HD 不可直接比**——(3) 的旧快照 `test_curve.csv` 只有 5 列（无 hd95），表里的 1.22 是 medpy `hd` 口径，本节 (4) 是 HD95。

读法：XNet 比同底座 U-Net 高约 0.5%（方向为正、不作结论），HD 同向（1.11 < 1.14）；GobletNet 原版 λ=0.3 最差（HD 1.22），**把 λ 置 0 后回升到 87.15（相对 U-Net +0.60、与 XNet 87.06 持平），说明原配置里 0.3 的 LL 回灌是负资产**——高频支一旦拿到低频能量就会退化成第二个语义支，FAM 互标定失去意义。GobletNet 垫底是方法与数据不匹配，不是复现问题（端口逐行对照官方，偏离项论文自证影响小）：它的设计标准来自电镜 EM——无散斑噪声、边界=锐利高频响应，假设「瓶颈只在高频细节」；颈动脉超声里高频子带被乘性斑点噪声主导、斑块边界是低对比度渐变，独立高频编码支补进来的是噪声（原 λ=0.3 配置参数 133M 为 U-Net 的 2 倍仍倒退，排除容量因素；λ=0 版虽追平 XNet，仍只是把高频支还原成第二个普通编码支，没有拿到任何超出同底座 U-Net 的净增益）。这与本项目证据一致：边缘图喂大主干零增益（§2(5)）；同域的 BDFR-Net 涨点靠的是特征级解耦+门控，不是输入端再开高频骨干。

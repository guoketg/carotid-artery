## 颈动脉斑块超声分割：公开指标区间（作为本项目基线参照）

### 结论（截至本轮）

1. 2D B 型超声斑块分割的 Dice 公开区间约 **0.69–0.90**，主流深度模型落在 **0.85–0.90**；HD95 很少被报告，边界质量普遍缺乏量化。
2. 现有工作**几乎没有**做「同一骨干 + 参数匹配」的融合消融，多数是「换一个更强的网络」再比 Dice，因此文献里的增益不能直接归因到注意力/融合。
3. 与我们的指标口径（Dice/ASSD/HD95/DeltaArea + 病例级配对检验）可比的论文极少，DeltaArea 基本没人报。
4. **公开颈动脉数据的 Dice 普遍被划分方式抬高**：DCLA-Net 的颈动脉子集 1100 张图只来自 **11 个受试者**，且原文明确写「无 subject id，无法做 patient-level 划分」，只能随机 3:1:1 —— 同一受试者的近邻帧同时落进训练与测试，Dice 0.9493 属于受试者泄漏下的乐观值。我们的病例级划分结果**不会**、也不应该和这类数字直接比大小。
5. **颈动脉上唯一贴题的「多分支」工作（MBFF-Net）不是双编码器**：它只有 **1 个 ResNeXt101 编码器**，多分支发生在**同一编码器的每一层内部**（多尺度 / 多上下文空洞 / 颈动脉壁先验三支）。所以「颈动脉 + 双编码器」在已读文献里**依然没有先例**，我们的「共享权重双输入」与「两个独立同构骨干」两种双支路方案仍属自证范畴。
6. **颈动脉上最有效的单项不是融合模块，而是显式边界监督**：MBFF-Net Table 1 里 BPS（最浅层特征受边界损失监督后回注各层）单独 **+0.044 Dice**，比它的多尺度支（+0.044 同量级但需配合）/多上下文支（+0.022）/颈动脉壁先验支（+0.022）都大或相当，且是全表最大单跳。这提示「边界约束」是比「再加一条支路」更便宜的候选（见 `technical-design.md`「未排期候选：显式边界监督」）。

### 条目

**MICCAI 2021（LNCS 12905, pp. 313–322，DOI 10.1007/978-3-030-87240-3_30）** — MBFF-Net: multi-branch feature fusion network for carotid plaque segmentation（Mi, Bao, Wei, Xu, Yang；清华深研院 + 深圳市人民医院；**已读全文，含 Table 1/2 与 Eq.1–6**）
- 数据：**430 张颈动脉纵切（CLS）B 型超声**，768×576 裁切后缩到 256×256；两台机器（Philips iU22 L9-3、GE logiq E9 9L，均 9 MHz）；训练 330 / 测试 100，**按图随机划分，不是病例级**。
- 结构（Sec. 2）：**单一 ResNeXt101 编码器**；先用作者前作 IMD-CNN（patch-wise）检测颈动脉壁/内膜-中膜区域，作为**先验图**输入；每层放一个 MBFF 模块，内含**三条支路**：
  1. 多尺度（Eq.1）：`concat(Φ_m, MSF) → 两层卷积 → Softmax → a_m`，`α_m = Φ_m + a_m`；
  2. 多上下文（Eq.2）：`β_m = f_conv(concat(d_3^2(Φ_m), d_3^4(Φ_m), d_3^6(Φ_m)))`，即 3×3 空洞率 2/4/6 并联；
  3. 颈动脉壁先验（Eq.3–4）：仿射调制 `(λ_m, ρ_m) = T(Φ_m)`，`γ_m = Φ_m ⊗ λ_m + ρ_m`；
  - 合并（Eq.5）：`Φ̂_m = f_conv(concat(α_m, β_m, γ_m))`。
- 边界保留结构 BPS：最浅层特征 + MSF 拼接受**边界损失**监督，再注入每一层细化特征；最终预测在多个层级上取平均。损失（Eq.6）= 多监督点 BCE 加权和 + 边界损失，权重经验取 1。
- 消融（Table 1，Dice / IoU / Precision / Recall）：
  - baseline 0.666 / 0.577 / 0.900 / 0.627
  - +DC 0.683；+CAW 0.688；+MSF 0.710
  - 三支全开 **0.736 / 0.647 / 0.896 / 0.710**
  - +BPS **0.780 / 0.702 / 0.849 / 0.797**
- 对比（Table 2，Dice）：PSPNet 0.585、ResUNet 0.621、U-Net 0.630、SegNet 0.687、DenseUNet 0.778、Ours **0.780**。
- 关键缺陷：① 只有 Dice/IoU/Precision/Recall，**没有 HD95/ASSD/面积误差**；② **没有 Params/FLOPs**；③ 无显著性检验；④ 按图随机划分，同一病人多帧会泄漏；⑤ 相对 DenseUNet 只 **+0.002**，却多了 6 个模块 + 一个额外检测网络（IMD-CNN）；⑥ 它复现的 U-Net 只有 0.630，明显低于同任务其他文献（0.85+），协议差异大，Table 2 的横向比较不可直接采信。
- 与本项目关系：① **修正了此前「颈动脉多分支 = 双支路编码器」的误解**，文献里仍无双编码器先例；② 它的外部信息源只有「颈动脉壁先验」这一路，单加 +0.022，说明**引入真正的第二路信息才值钱**，我们的高频能量通道属于同类尝试；③ **BPS 单项 +0.044 是本表最大单跳**，比任何特征支路都大 → 记为 `technical-design.md`「未排期候选：显式边界监督」，若这组对照实验全无效应优先试它；④ 它不报 HD95，因此不能证明「融合改善边界」，我们的评估口径仍有差异化空间。

**Frontiers in Physiology 2025** — DualPlaqueNet: dual-branch structure and attention for carotid plaque segmentation and size prediction（PMC12303906，已读全文）
- 数据：单中心 287 例患者，每人 1 张图，随机 7:1:2（训练 200 / 验证 28 / 测试 59），增强后训练集 1600。
- 方法：U-Net 双分支（一支全局语义、一支局部细节）+ ECA 通道注意力装在编码器每一层 + 分割/尺寸回归联合损失。
- 结果（Table 11，测试集）：U-Net 85.46±1.33、ResUNet 86.13±1.00、TransUNet 86.79±1.28、DualPlaqueNet **89.95±1.10** DSC。
- 关键缺陷：① 没有「单分支 vs 双分支」消融，也没有参数匹配对照，+3.2 Dice 同时混入了多任务回归损失、ECA 和双分支三个变量；② 只报 DSC/ACC，无 HD95、无面积误差；③ 随机划分，同一患者虽只有 1 张图，但仍未做病例级交叉验证；④ 测试集仅 59 例，无显著性检验。
- 与本项目关系：**不能**用它证明「双骨干有效」。它只能作为「颈动脉斑块 Dice 可到 ~0.90、TransUNet 在该数据规模下与 U-Net 同级」的参照。

**Computers in Biology and Medicine / 相关期刊 2022** — 颈动脉斑块分割的 U-Net 系列基准（PMC9604424，已读全文）
- 数据：ICA 970 张、CCA 379 张（同一训练协议、同一划分，属少见的公平对比）。
- 结果：ICA 上 UNet **90.02±3.53** vs Attention-UNet **89.90±3.69**（注意力门控 −0.12）；CCA 上 UNet 86.07±6.17 vs Attention-UNet 86.50±5.94（+0.43）；CCA 上 UNet++ 87.48±5.57 优于两者。
- 参数（Table 2）：UNet 31.03M，Attention-UNet 31.90M（+0.87M）。
- 与本项目关系：**这是目前最贴近我们任务的负结果证据**——在颈动脉超声上，加注意力门控的增益在 ±0.4 Dice 内、方向不稳定。我们要证明融合有效，必须跨过这个噪声底。

**（IMT，非斑块）2025** — 10 种 U-Net 变体在颈动脉内膜中层厚度上的同协议比较（PMC12785940，已读全文）
- 结果（Table 9）：U-Net 0.8148±0.0032、AttentionUNet **0.8216±0.0034**、UNet++ 0.8198、TransUNet 0.8143、UNext 0.8051。
- 参数（Table 8）：U-Net 7.85M vs AttentionUNet 31.39M（4 倍宽，滤波器 64–1024 vs 32–512）→ 增益与容量混淆；训练时间 3611s vs 2007s（Table 11）。

## 双骨干 / 双输入融合：到底有没有「两路编码器」的可靠增益

### 结论（截至本轮）

1. 公开文献里**没有**找到「同一输入的两个派生视图 + 参数匹配的单/双编码器对照」这种实验；现有双分支工作几乎都是**两路不同任务**（body/boundary、分割/回归、空间/频率），且缺少单分支消融。
2. 双分支带来的增益普遍只有 **+0.5 ~ +1.5 Dice**，且 HD95 往往不变；增益经常来自**额外的监督信号**而不是融合结构本身。
3. 没有任何一篇报告「两路独立同构大骨干（各 100M 级）」在小样本超声上稳定优于共享权重双输入——这条路我们得自己做对照，不能引用别人。
4. **增益的归属很清楚**：DCLA-Net 里「加第二条编码器」值 +0.47~+0.63 Dice，而后面两个融合模块合计只有 +0.18~+0.22（Table 1）；HiImp-SMI 里跨支注意力 MCAB 同域 +0.40、HD 变差、跨域掉点（Table 5）；MSFA-Net 里融合模块 ACAF 的净贡献只有 +0.45~+2.18，且任一单模块单独恢复辅分支就能拿到 +8.5（Table 4）。**融合模块不是收益来源，第二路信息源才是。**
5. 已读到的**双编码器几乎全部是异构互补**（Transformer + CNN：DCLA、HiImp-SMI、MSFA-Net、DEFI-Net；普通卷积 + row-column 卷积：ESTAN）。**没有一篇是「两个同构骨干处理同一张图的两种视图」**——我们的「两个独立同构骨干」方案依然没有文献先例，风险自担。
6. **交互比融合更值钱**：DEFI-Net 的 GLIL（用对方注意力图交叉门控）单独 +1.66 DSC / HD95 −25%，而 GLFF（concat + 通道注意力）只有 +0.67 / −20.5%（Table 4）。这直接决定我们 CGAF 的设计取向：**双向、用对方的权重、逐层做，而不是在瓶颈处做一次 concat 后再算注意力**。
7. **唯一一篇「同一张图派生两种视图 + 双输入」的工作（MS-Net），增益只有 +0.003~+0.008 Dice，比它自己的 DWT 结构改动还小**：双支（W-Unet 高分辨率 + BFF-Net 低分辨率）相对最好单支，LV Dice **+0.0083**、LA Dice **+0.0034**（Table 1）；而单独把下采样换成 DWT，LA Dice 就 **+0.0296**（Table 2）。这再次印证「结构/信息源 > 融合算子」，也说明**同一图像派生视图的双输入增益天花板很低**，我们的原图通道＋高频能量通道不应期待大幅涨点。
8. **MS-Net 在 LA 上还输给 U-Net 与 AIDAN**（Table 3：U-Net 0.9155、AIDAN 0.9140、Ours 0.9061）——双分支不是稳定占优，小数据上更可能打平或掉点。

### 条目

**IEEE ISBI 2021, pp. 1402–1405（DOI 10.1109/ISBI48211.2021.9434157）** — MS-Net: Multi-scale Wavelet Network Algorithm for Pediatric Echocardiographic Segmentation via Feature Fusion（Zhao, Xia, Guo, Du, Chen, Wang, Lei；深圳大学 + 深圳儿童医院；**已读全文，含 Table 1/2/3 与 Eq.1–6**）
- 数据：**127 例**四腔心（4CH）超声视频，**按病例划分** 100 训练 / 27 测试，抽帧得 **3654 / 831** 张，448×448。
- 结构（Sec. II）：**两分支，输入不同**——
  - Input2（高分辨率图）→ **W-Unet**：4 层（64–128–256–512），**DWT 替代下采样**、解码用 IDWT 上采样，配空间注意力加权，三层解码特征相加；
  - Input1（低分辨率图）→ **BFF-Net**：ResNet-50 + 自顶向下/自底向上双向传播 + PAM/CAM（Eq.1–2）；
  - 融合（Eq.3–4）：`F3 = F1 + F2` 逐元素相加后 Softmax；两分支各带辅助损失，并加分支间 **L1 一致性损失**（α=β=0.5，Eq.5–6）。
- 结果（Table 1，Accuracy / Jacc LV / Jacc LA / Dice LV / Dice LA）：
  - W-Unet 0.9886 / 0.8780 / 0.8274 / 0.9338 / 0.9027
  - BFF-Net 0.9866 / 0.8949 / 0.7130 / 0.9439 / 0.8289
  - 双支 **0.9910 / 0.9104 / 0.8332 / 0.9522 / 0.9061**
  - → 相对最好单支：LV Dice **+0.0083**、LA Dice **+0.0034**。
- DWT 开关（Table 2）：无 DWT 0.9899 / 0.9029 / 0.7873 / 0.9482 / 0.8765 → 有 DWT 0.9910 / 0.9104 / 0.8332 / 0.9522 / 0.9061，即 **DWT 单独贡献 LA Dice +0.0296**，**大于双分支本身的增益**。
- 对比（Table 3，Dice LV / LA）：U-Net 0.9511 / 0.9155、AIDAN 0.9520 / 0.9140、Ours 0.9522 / **0.9061** → **LA 上不如 U-Net 与 AIDAN**，LV 上也只与 AIDAN 打平。
- 关键缺陷：① 无 HD95/ASSD、无面积误差；② 无 Params/FLOPs；③ 无显著性检验；④ 单中心、单病种、样本量小（27 例测试）；⑤ 两分支**不同构**（W-Unet vs ResNet-50），不是「同构双骨干」；⑥ 融合只是逐元素相加 + Softmax，未做跨支交互。
- 与本项目关系：① 它是「同一张图的两个尺度视图 + 双输入」最贴近的先例，**增益上限只有 +0.003~+0.008 Dice**，直接下调我们对双支路方案的期望；② 它最强的单项是 **DWT 替换下采样（+0.0296）**，而不是融合——提示「把频域信息做进结构」比「再开一条输入支路」更值钱（对应 `technical-design.md`「其他频域手段」的 ⏸ 待定项）；③ 它**按病例划分**，是本批文献里划分口径最规范的之一，其「双支不总是赢」的结论可信度较高；④ 它的 L1 一致性损失是低成本的稳定手段，若我们双支训练出现分歧可参考。

**arXiv 2411.11116（2024）** — DBF-Net: A Dual-Branch Network with Feature Fusion for Ultrasound Image Segmentation（已读全文）
- 数据：BUSI / UNS / UHES 三个超声数据集。
- 方法：body 分支 + boundary 分支，各带监督，FFS 模块做双向特征融合（不是 concat），总参数 3.2M（Table 4）。
- 结果（BUSI）：单分支 baseline 79.91±9.43 / HD 7.39±0.35；加 body+boundary 监督 79.91；加 FFS+FFM **81.05±10.44 / HD 7.35±0.27**（Table 5、Table 6）。即双分支+融合约 **+1.1 Dice，HD 基本不动**。
- 附带事实（Table 3）：在其设置下 TransUNet 只有 **31.40 DSC**（BUSI），远低于 U-Net 系；作者归因于小数据从头训练。
- 与本项目关系：① 双分支的天花板比想象低，我们要把「显著」阈值定在 ≥1 Dice 且 HD95 也要动；② TransUNet 在小数据上非常脆弱，**预训练权重不能省**，且 batch/学习率要单独调。

**arXiv 2512.17278v1（2025-12）** — WDFFU-Mamba: Wavelet-guided Dual-attention Feature Fusion Mamba for BUS（已读全文，含 Table 1/2/3）
- 数据：BUSI + BUS（公开乳腺超声，5 折）。
- 方法：VM-UNet 三级主干；WHF（单级 Haar → 对 HH 加 σ=1.0 高斯、LH/HL 加 σ=0.5 → 逆变换重建 → 高频引导 + Non-local）注入编码器深层；DAFF（通道注意力用 1×1 卷积替代 FC，空间注意力用 7×7 小波卷积，两路权重相乘后**送到解码器每一级的 skip**）。
- 消融（Table 1，BUSI / BUS 的 Dice 与 HD95）：

| 配置 | BUSI Dice | BUSI HD95 | BUS Dice | BUS HD95 |
|---|---|---|---|---|
| Baseline（三级 VM-UNet，5.65M） | 81.42±2.27 | 26.78±5.70 | 82.12±3.79 | 19.57±8.27 |
| +WHF（仅小波高频引导） | 83.10±3.01 | 18.93±6.75 | 84.92±1.91 | 22.22±5.72 |
| +DAFF（仅双注意力融合） | 82.41±3.93 | 16.08±6.73 | 82.62±2.02 | 22.44±4.97 |
| +WHF+DAFF | **84.48±2.89** | **13.28±5.17** | **85.20±1.75** | **17.90±4.38** |

- 解读：小波高频引导单独 +1.68 / +2.80 Dice；双注意力融合单独只有 +0.99 / +0.50，且在 BUS 上 HD95 反而变差（19.57→22.44）。两者叠加才同时改善 Dice 和 HD95。
- 与本项目关系：① **小波信息值得做，但融合模块本身增益很小**，与我们旧 WGA 的实测（±0.002）一致；② 他们的融合放在**每一级 skip**，不是只放瓶颈——支持我们做浅、中、深三级；③ 注意他们的 WHF 是「对特征图做小波」，不是把三通道预处理图喂进第二个骨干，所以**仍不能回答双骨干问题**。

**Frontiers in Physiology 2026** — DCLA-Net: dual-encoder cross-level alignment network for ultrasound segmentation（已读全文，含 Table 1–5）
- 数据：异位妊娠（Ectopic）私有集 + **Carotid 公开集 1100 张、仅 11 个受试者**；随机 3:1:1（660/220/220），原文明确说明「无 subject id，无法做病例级划分」。
- 结构：双编码器（U-Net 编码器 + Transformer 编码器）→ MSCAFM（多尺度跨层对齐融合）→ DAFM（双注意力融合）→ 解码。
- 消融（Table 1，Dice）：
  - Ectopic：U-Net 0.7806 / 8.96M → +双编码器 0.8273 / 12.70M → +Transformer 0.8363 / 9.16M → +MSCAFM 0.8422 / **98.47M / 145.43 GFLOPs** → +DAFM 0.8455 / 108.95M / 177.74 GFLOPs。
  - Carotid：U-Net **0.9493** / 8.96M → +双编码器 0.9556 → +Transformer 0.9575 → +MSCAFM 0.9581 → +DAFM **0.9597** / 108.95M / 177.74 GFLOPs。
- 解读：**双编码器贡献 +0.47（Ectopic）/ +0.63（Carotid）Dice，两个融合模块加起来只有 +0.18 / +0.22**，代价是参数 8.96M→108.95M（×12）、算力 16.79→177.74 GFLOPs（×10.6）。这是目前读到**最直接的「融合模块本身收益极小」的量化证据**。
- 与本项目关系：① 支持我们先做「两路编码器」再谈融合，而不是把希望压在注意力模块上；② 它的融合放在跨层级（多尺度）而非单点，可对应我们的浅、中、深三级；③ 它的 Carotid 数字（0.9493）不可作为我们的对标基线——受试者泄漏 + 划分不同；④ 我们必须在 105M 量级内做，不能照抄它的 ×12 扩容。

**Frontiers in Physics 2025** — HiImp-SMI: implicit transformer framework with high-frequency adapter（已读全文，含 Table 1–5）
- 数据：Kvasir-Sessile（196 张，二分类息肉）+ BCV（30 例 CT，13 器官）；跨域测 CVC-ClinicDB / AMOS；6:2:2 划分。
- 结构：SAM ViT-B 编码器（**冻结权重 + LoRA rank=4**）+ 一条轻量卷积分支；"dual-branch" 指 ViT 深支 vs Conv 浅支，**不是两个同构骨干**。瓶颈特征 F_b 为两支共享。
- MCAB 的 Q/K/V 设计（Eq.4）：深支 Q=W·F_d，K=W·[F_b;F_s]，V=W·F_s；浅支对称（Q=F_s，K=[F_b;F_d]，V=F_d），再用 **Deformable Attention** 做跨支对齐。即「深查浅、浅查深」的双向跨注意力 + 共享瓶颈作为 key。
- 消融（Table 5，Kvasir-Sessile 同域 / →CVC 跨域）：
  - 无模块：Dice 91.81 / HD 11.80 / IoU 84.86；跨域 89.07 / HD 24.06 / 80.29
  - +CAB：92.02 / 11.28；跨域 88.94 / 24.66
  - +CAB+MCAB：92.42 / **11.50（HD 反而变差）**；跨域 **88.87（Dice 反而下降）** / 22.12
  - +CAB+MCAB+VCFB：**92.51 / 9.98**；跨域 **91.46 / 21.03**
- 解读：三个模块**同域只涨 +0.70 Dice**，其中跨支注意力 MCAB 单独 +0.40 但 HD 变差、跨域还掉点；真正的 +2.39 跨域增益来自 VCFB（ViT-Conv 选择门，F_out = F_d⊙ω + F_s⊙(1−ω)）。全文**未给参数量/FLOPs 对照**。
- 与本项目关系：① 它的「双向跨注意力 + 共享瓶颈 key」正是我们 CGAF 想做的事，可作为结构参照；② 它同样没有「双同构骨干」的对照，我们的两种双支路方案仍是空白；③ 再次印证：**融合模块在同域提升 ≤0.7 Dice，主要价值在跨域/泛化**——而我们的任务只有单中心数据，跨域收益无法兑现，因此必须把评估重心放在 HD95/ASSD 与配对检验上。

**Digital Signal Processing 168 (2026) 105547** — MSFA-Net: multiscale feature enhancement and fusion attention based dual-encoder network for breast ultrasound segmentation（Liu et al.；**已读全文，含 Table 1–5**）
- 数据：BUSI（benign / malignant / fusion 三个版本）、BUS、UNS（11143 张，5 折）。
- 结构（Fig. 1、Fig. 2）：**两条异构编码器并联**——主编码器是预训练 PVTv2（Transformer），辅编码器是自研 EA（纯卷积，Table 5 给出 **仅 4M 参数**）。EA 内部又把通道一分为二，走 MSFE（多尺度并行卷积）与 FAM（1×1 卷积 + 融合注意力）两个子分支。两级特征由 **ACAF（自适应跨注意力融合）** 逐层合成统一特征流，再进解码器。
- **关键事实：两条编码器不同构、不共享权重**；这是「Transformer + CNN」互补型双编码器，不是「两个同样的骨干」。
- 参数量（Table 5）：MSFA-Net **33M / 7 GFLOPs**；MNFE-Net 59M/9G，MF-Net 34M/7G，MFAR-Net 30M/9G，MA-UNet 58M/155G。
- 消融（Table 4，5 折；Baseline = PVTv2 + 两路**直接级联**，即两条分支都在、但融合方式是 concat）：

| 配置 | BUS Dice | BUSI-mal | BUSI-benign | BUSI-fusion |
|---|---|---|---|---|
| Baseline（PVTv2 + 级联） | 77.04 | 72.34 | 76.70 | 80.17 |
| +MSFE | 85.60 | 76.30 | 79.44 | 81.51 |

- 解读（这一条非常重要）：**任何一个模块单独加回去都能在 BUS 上拿到 ~+8.5 Dice**（MSFE +8.56、FAM +8.29、ACAF +8.53），而「MSFE+FAM 但不加 ACAF」只有 84.56，**反而低于任一单独模块**。这说明 Baseline 的低分主要来自「辅分支被 1×1 卷积废掉」，而不是融合方式差；一旦辅分支恢复，增益就基本吃满。**融合模块 ACAF 在已有 MSFE+FAM 之上的净贡献只有 +2.18（BUS）、+0.51（BUSI-mal）、+0.67（benign）、+0.45（fusion）**。

- 与本项目关系：① 它是「两路互补编码器」里结构最接近我们的公开实现，但**仍然不是两个同构骨干**，「两个独立同构骨干」的文献空白没有被填上；② 它给出的最佳证据恰恰是「收益来自第二路**互补信息**，不是融合模块」——PVT 提供全局、CNN 提供局部；我们的原图通道与去噪重建通道、高频能量通道是**同一张图的派生视图**，互补性远弱于 Transformer vs CNN，所以对「两个独立同构 210M 骨干」的期望必须下调；③ 更合理的优先级是 **共享权重的双输入方案（同一骨干、两份不同输入视图）**：权重共享把「新增参数」压缩到 0，而信息增量仍来自高频能量通道，这与 MSFA-Net 的「补信息 > 加模块」结论同向。

**Applied Sciences 2025, 15(7):3785** — DEFI-Net: medical image segmentation network based on dual-encoder interactive fusion（Huang/Yang et al.；**已读全文，含 Table 4**）
- 数据：Synapse（CT 多器官）、ACDC（心脏 MRI）、Kvasir-SEG（内镜息肉）。输入统一 224×224，SGD，batch 4，150 epoch。
- 结构（Sec. 3.1–3.3）：Transformer 编码器（3 个 stage，patch 4/2/2，C′=320）+ **ResNet-34** CNN 编码器，取 ResNet 第 2/3/4 stage 与 Transformer 三个 block 对齐到同一尺度。
  - **GLIL（跨支交互）**：每一层用两个并行空间注意力（avg+max pool → concat → 7×7 conv → sigmoid）分别得到 ω_t、ω_c，然后**交叉调制**：F_c ← F_c + α·(F_c ⊗ ω_t)，F_t ← F_t + β·(F_t ⊗ ω_c)。即「用 Transformer 的全局权重去门控 CNN 特征，用 CNN 的局部权重去门控 Transformer 特征」，**在编码器每一层都做，并往后传**。
  - **GLFF（融合）**：先 concat，再 SE 式通道注意力，最后用 (ω_t+ω_c) 再调制一次：F = F_CA + γ·((ω_t+ω_c) ⊗ F_CA)。
- 消融（Table 4）：

| 配置 | Synapse DSC | Synapse HD95 | ACDC DSC | ACDC HD95 | Kvasir DSC |
|---|---|---|---|---|---|
| Concat（双编码器直接拼接） | 80.98 | 24.17 | 88.72 | 1.44 | 85.54 |
| +GLIL | 82.64 | **18.45** | 91.83 | 1.11 | 86.50 |
| +GLFF | 81.65 | 19.21 | 91.62 | 1.18 | 86.14 |
| GLIL+GLFF | **83.29** | **18.15** | **92.02** | **1.08** | **87.45** |

- 解读：① **跨支交互（GLIL）单独 +1.66 DSC / HD95 −5.72**，明显大于**融合（GLFF）单独 +0.67 / −4.96**；② 两者叠加只再多 +0.65 / +0.30——**交互已经把大部分收益吃掉了**；③ 收益主要体现在 **HD95**（24.17→18.15，−25%），Dice 只 +2.3，这正好是我们想要的指标形态。
- 缺陷：没有参数量/FLOPs 表，作者在结论里自承「dual-encoder structure introduces significant computational overhead」；没有「单编码器 + 同参数」对照，也没有融合层级（哪一层）的消融。
- 与本项目关系：① GLIL 的「**用对方的注意力图去门控自己的特征**」比我们的 AG（只在本支内部算 gate）强一个层级，且实现代价极低（每层两个 CBAM 空间注意力），**这是 CGAF 应该吸收的设计**：双向、用对方权重、逐层做；② 它证明「先交互、再融合」顺序正确，我们的浅、中、深三级应默认带交互而不是只做 concat 后处理；③ HD95 的改善幅度（−25%）给了我们一个可比的效应量参照。

**Healthcare 2022（PMC9690845）** — ESTAN: Enhanced Small Tumor-Aware Network（乳腺超声，已读全文 Table 4/5/6）
- 结构：两条编码器支路（一条标准卷积、一条 row-column-wise 卷积以贴合乳腺解剖），解码器**从两条编码器各取 3 个 skip 层级做融合**。这正是「多层级融合」的工程先例。

## skip 融合与注意力门控（AG）的真实增益

### 结论（截至本轮）

1. **AG 的增益高度依赖是否已有预处理/增强**：在无预处理时 +0.9 Dice，一旦加了 CLAHE 类预处理，AG 增益归零（AttResDU-Net Table I，两行数字完全相同）。
2. 颈动脉超声上的 AG 增益 ≤ ±0.4 Dice（上一节 PMC9604424），与本项目旧 WGA 的实测一致。
3. 融合模块越「重」，单独使用的边际收益越小（WDFFU-Mamba 的 DAFF 单独 +0.5~1.0）；真正的收益来自「额外信息源 + 融合」的组合。
4. 注意：多数论文只报 Dice，不报 HD95/ASSD；只报 Dice 的融合增益不能作为「边界更好」的证据。
5. **融合层级（浅层 / 中层 / 深层）的逐级消融，至今没有找到任何一篇。** ESTAN 从两条编码器各取 3 级、WDFFU 在解码器每一级都放 DAFF、DCLA 用多尺度 MSCAFM、DEFI-Net 的 GLIL 在三个金字塔层都做交叉门控，全部是「多级全开」且没有关掉某一级的对照。我们的融合位置单点扫描实验在这个点上是空白，可以自证，但也意味着**没有文献能替我们背书**，必须自己跑出趋势。
6. **闭环比单纯门控更有依据**：DEFI-Net 的 GLIL 不学一个标量 gate，而是**把对方支路的空间注意力图拿过来调制自己的特征**（F_c ⊗ ω_t、F_t ⊗ ω_c），单这一项就有 +1.66 DSC / HD95 −5.72（Table 4）。我们旧 WGA 是在本支内部算 gate，信息回路是闭合的，这是它测不出增益的结构性原因。

**arXiv 2306.14255v1（2023）** — AttResDU-Net（ISIC2018 皮肤病变，已读全文 Table I）
- 结果（DSC）：AttDU-Net（**无 AG**）90.73；Half-Attention（部分 skip 加 AG）90.90；Full-Attention（全部 skip 加 AG）**91.64**；AttDU-Net + CC（CLAHE 预处理，无 AG）**91.64**；AttResDU-Net + CC 91.68。

## 小波 / 频域预处理：级数、阈值、是否稳定提升

### 结论（截至本轮）

1. 小波类方法在超声上的**稳定收益集中在边界类指标（HD95）**，Dice 收益中等（+1~3），与我们的目标一致（我们要的是 HD95/ASSD 改善）。
2. 目前看到的实现分两类：**① 输入级预处理**（本项目的原图通道、去噪重建通道、高频能量通道属此类）；**② 特征级小波分解/下采样**（FMC-Net、WDFFU 的 WHF）。文献里 ② 的证据更强、更多，① 很少被单独消融。
3. 「用 DWT 替代 maxpool」这种改下采样的做法收益最直接（HD95 大幅下降），但它改变的是网络结构而不是输入通道，**不能直接搬来解释我们的三个输入通道**。
4. **输入级去噪替换原图，证据是负的**：133 个同域 case 中只有 22 个显著更好、24 个显著更差，Friedman 排名上没有任何去噪方法优于原图（denoising benchmark Table V）；把去噪特征与分割特征融合（多任务）反而掉点（Table A14）。
5. 但目前**没有一篇测过「原图 + 去噪图」双输入/双通道**。也就是说：文献反对的是「用去噪图**替代**原图」，没有反对「去噪图作为**辅助视图**」。这是去噪重建通道唯一还站得住的位置，也决定了它只能是消融项而不是主方案。

**TechRxiv 预印本（2023-11-16，v3）** — Is denoising necessary for ultrasound image segmentation deep learning: review and benchmark（Liu et al., 上海交大；**已读全文，27 页**）
- 设置（Sec. IV + Table IV）：4 个公开超声集 + 2 个自采（乳腺、超声心动），**7 种去噪**（Lee、OBNLM、DPAD、PFDTV、GLM、DnCNN、SAR-BM3D）× **6 个分割模型**（U-Net、SK-U-Net、CE-Net、RF-Net、CDM、DAEFF-Net）+ 多任务去噪-分割（SFS block）。输入均为**单通道**，即「把原图换成去噪图」，不是「原图 + 去噪图」。每个组合跑 30 次重复训练消除随机性。

- 多任务去噪+分割（Table A14）：用 SFS block 融合去噪子网与分割子网的特征，**性能明显劣于单任务分割**。作者归因于去噪子网把干扰引入分割子网。
- 耗时（Table VII）：DnCNN 0.008–0.056 s，Lee 0.010–0.042 s，DPAD 0.1–2.2 s，而 GLM 最高 276 s、SAR-BM3D 最高 128 s（单张）。
- 作者自承局限：多数数据集用**随机 6:2:2 划分**（非病例级），且未考虑「speckle 本身是有利特征」的情形。
- 与本项目关系：**这是对去噪重建通道最不利、也最需要正视的一篇**。① 它证明「用去噪图替换原图」在超声分割上收益不稳定、且换更强模型/更多数据的收益远大于去噪；② 它的多任务融合实验说明「把去噪特征塞进分割网络」会掉点——这直接警告我们不要把去噪重建通道当成主要增益来源；③ 但它**没有测「原图 + 去噪图双通道/双输入」**，所以不能完全否定去噪重建通道作为**辅助视图**（我们的原图通道始终保留）；④ 结论落到实验设计：去噪重建通道必须降级为**消融项**，主方案用原图通道 + 高频能量通道（高频细节，不是去噪），并且所有对比都要做配对检验，不能只看均值。

**PLOS One 2022** — Comparative analysis of wavelet transform filtering systems for noise reduction in ultrasound images（pone.0270745）
- 只比较了滤波质量指标（PSNR/SSIM 类），**没有做分割任务的下游评估**。
- 与本项目关系：只能作为「小波去噪本身有效」的依据，不能作为「去噪能提升分割」的依据。暂不引用。

## 通道/空间注意力（SE / CBAM）在医学分割的实际增益

### 结论（截至本轮）

1. 当基线已经很强（Dice≈0.95）时，把编码器中的一个卷积块换成 CBAM **没有带来任何提升**，作者因此改用更简单的默认模型。
2. 现有证据的方向与「skip 融合与注意力门控」一节一致：通道/空间注意力在**低对比、小目标、边界模糊**的病例上才有机会体现，在已经饱和的数据上只会增加参数。
3. 我们的颈动脉数据上，baseline 已经接近文献上限（Dice 0.85–0.90），因此**不能指望 CBAM/SE 这类轻量注意力带来统计显著的提升**；要做就必须做「跨视图选择」这种 AG 做不到的事（见「skip 融合与注意力门控」一节结论 1）。

### 条目

**Insights into Imaging 2022（PMC9813298）** — 3D nnU-Net ± CBAM 的对照（子宫 MRI，5 折交叉验证）
- 两模型均训练 500 epoch，唯一差别是把编码器第 2 个 block 换成 CBAM（其余超参由 nnU-Net 指纹自动决定，属于少见的受控对照）。
- 结果（正文 Results 节）：默认 3D nnU-Net 平均 Dice **0.95±0.05**，CBAM 版同为 **0.95**；平均相对体积误差 3.79%（默认）vs 3.70%（CBAM）。作者明确写「no significant benefit」，最终选用默认架构。
- 与本项目关系：这是「同一框架、只换注意力模块」的干净负结果。虽属 MRI，但支持我们的判断：**在强基线上加轻量注意力不会有统计显著收益**，我们的融合模块替换实验（AG / 通道+空间注意力 / 双向跨注意力 CGAF）必须报参数量与配对检验，不能只看均值。

## 本轮检索对方案的硬结论（已回填 `technical-design.md`）

1. **去噪重建通道（对数域软阈值去噪图）不能作为主方案成分。** denoising benchmark 的 133 个同域 case 里只有 22 个显著更好，Friedman 排名无方法优于原图，多任务融合还掉点（Table V / A14）。保留去噪重建通道唯一合理的形态是「辅助视图消融项（伪小波支路对照实验的一个分支）」，不能写进主模型。
2. **「两个独立同构 210M 骨干」优先级下调，「共享权重双输入」优先。** 所有已读双编码器都是**异构互补**（Transformer+CNN、普通卷积+row-column 卷积），收益来自互补信息；原图通道与高频能量通道是同一张图的派生视图，互补性弱，再复制一份同构权重不产生新信息，却把显存翻倍到 8GB 边缘之外。**MS-Net（Table 1）是这条判断最直接的量化证据**：同图派生双视图只值 +0.003~+0.008 Dice，而它自己把下采样换成 DWT 就值 +0.0296（Table 2）。
3. **CGAF 必须改成「跨支交互 + 用对方注意力图门控」，且逐层做。** DEFI-Net 的 GLIL 单独 +1.66 DSC / HD95 −5.72，而 concat+通道注意力（GLFF）只有 +0.67 / −4.96（Table 4）；MSFA-Net 显示「恢复第二路」本身值 +8.5、融合模块净贡献只有 +0.45~2.18（Table 4）。判别标准因此改为：**看 HD95/ASSD 是否显著改善，而不是看 Dice 涨多少**。
4. **期望值必须整体下调，门槛实验从「原图通道＋高频能量通道双通道早融合、单骨干、无注意力」这一项起。** MBFF-Net 加了 6 个模块 + 1 个先验检测网，最终只比 DenseUNet 高 **0.002** Dice（Table 2），且不报 HD95/ASSD；MS-Net 双支在 LA 上还输给 U-Net（Table 3）。因此：这项门槛实验（高频能量通道进单编码器）不显著就不该继续堆双支路；若这组对照实验全部无效，优先转 **显式边界监督**（MBFF-Net BPS 单项 +0.044，全表最大单跳）而不是继续加融合模块。
